## 🔑 核心观点梗概

### 金三角为什么重要?

```
许多公司的失败不是因为"不赚钱"
而是因为三角的某个角特别弱:

❌ 赚钱但没现金 (好经营+差融资)
   → 黑字倒闭 (Profitable Insolvency)

❌ 有现金但投资差 (好融资+差投资)
   → 资本低效，股东回报差

❌ 有资产但不赚钱 (好投资+差经营)
   → 资产贬值，无法产生收益

✅ 三个角平衡
   → 可持续增长，股东价值最大化
```

### 降维管理的威力

**复杂的商业现实** (多维) 
→ **财务指标** (一维)
→ **清晰的决策标准**

例子：
```
iPhone公司好不好?
├─ 产品角度: 革命性设计
├─ 人员角度: 顶级工程师
├─ 市场角度: 强大品牌
├─ 战略角度: 生态系统
└─ 财务角度: ROE 120% → 说明上面一切都做得好!
```

### 三个角色的财务思维

| 角色 | 思维转变 | 关键能力 |
|------|---------|---------|
| **经营者** | 一维思维 → 财务思维 | 用财务指标指导经营 |
| **财务人员** | 报表员 → 业务顾问 | 找到财务背后的业务驱动因素 |
| **投资者** | 看故事 → 看数据 | 识别风险，评估真实回报 |
