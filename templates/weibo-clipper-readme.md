# 微博剪藏模板

导入文件：[weibo-clipper.json](weibo-clipper.json)。这是 Web Clipper 配置，不是 AI skill。

日常使用只需剪藏、改一个容易找回的标题、按需写自己的话。没有想法时也可以只保留原文；不需要 AI、蒸馏或评审。此处文件是可复用配置，移动文件不会更新浏览器中已导入的模板。

## 导入

1. 在 Web Clipper 设置的模板编辑页，点击右上角“导入”，选择这个 JSON 文件。
2. 核对模板名“微博 · 原文与我的想法”、行为“创建新笔记”、笔记位置 inbox、保管库 ZHPMind。
3. 在微博单条正文页面打开 Clipper，确认选中了这个模板。若其他模板先匹配了微博，把此模板移到那个模板前面；无需更改其他网站的模板。
4. 剪藏预览中确认原文非空、作者正确，并把“笔记名称”改成自己容易找回的主题短标题，例如“折叠屏的高端感从哪里来”，再保存。在 Obsidian 的“我的想法”下面直接写自己的话。

已导入旧版时，应在已有模板中替换“笔记名称”“笔记内容”并去掉 author 属性，或导入新版后停用旧版，避免两个微博模板同时匹配。更新模板不会自动重排过去的笔记。

## 版式

- “我的想法”在上方，留空供自己写，不调用 AI 补写。
- 原文放在细分隔线下面，默认折叠；标题显示作者，展开后可见发布时间、原文链接和正文。在 Obsidian 点击标题旁的箭头展开。
- 只有确实产生后续思考时，自己或 AI 再加“后来想到”，模板不预先放一堆空栏目。
- 文件名预填正文第一句的前 32 个字符，不使用网站通用标题、“微博-”前缀或长时间戳。保存前换成自己的短标题更好；不同微博开头相同可能重名，此时加作者或日期区分，不复用已有笔记。
- 标题只由文件名显示。正文不再生成一级标题，也不额外保存同名 title 属性；现有笔记的 title 属性不会自动改文件名。
- 属性只留来源、剪藏日期和 clippings 标签。作者与发布时间放在原文区，不重复占据顶部空间。

## 支持范围与检查

当前模板针对桌面版单条微博 URL，例如 https://weibo.com/1694917363/Rgzh9EMGx；不匹配首页、用户主页、搜索页、微博长文章或 m.weibo.cn 移动页面。

模板保留正文容器的 HTML 再转为 Markdown，以保留链接与容器内的图片等内容，不用 AI 改写原文。视频、转发微博及多图帖尚未验证，外链图片也不等于已经下载到本地。

长微博请先展开全文。若预览中正文为空或仍有“展开”而非全文，先不要保存；确认页面加载、全文展开，再试。站点结构变化时需要修订选择器，不用宽泛匹配整页来默默兜底。

此版本只抓正文，不读取手工选区或自动抓评论。要保留某条评论，可以单独引用并注明评论者，放在原文引用区内，与自己的想法分开。
