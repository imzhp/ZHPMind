视角  GitHub 前 CEO ：Nat Friedman 的一些信条

by  fonter

Nat Friedman 其人其事

和 Notion 早期天使投资人 Daniel Gross 是好朋友，搭档一起投资 AI、开源软件领域；

因为喜欢 费曼 Feynman，去 MIT 念书；

1991 年就开始接触互联网，称互联网才是其故乡；

创办过 2 家公司：Xamarin（跨平台开发软件，后被微软收购） 和 Ximian（ GNOME 平台的开源公司）；

后长期在微软工作，微软以 75 亿美元收购 GitHub 之后，一直担任 GitHub CEO 至 2021 年；

他的信条很有意思：

当今世界最大的机遇：支持哪些用技术创造未来的 developer/builder ，他们构建未来需要工具，投资这些；

科技的通缩效应将克服当今世界出现的最严重的货币政策错误。

作为人类，按照我们的喜好重塑宇宙是我们的权利(也许是我们的道德义务)。

技术，也就是真正的知识（过程只是），使这一切成为可能。

你努力的方向：提升天花板，而不是地板。

热情太重要了。

做那些让你兴奋的事情，其实要容易得多。

基于此，其实做大事可能比做小事更容易。

释放热情和能量是进步的必要投入。

兵贵神速。

与现实世界接触的越频繁，每单位时间学到的东西就越多；

加快会让你专注于重要的事情，因为你没时间去废话；

Slow is fake。

记住：一周是一年的 2%。

时间是分母，不是分子。

有效市场假说 EMH 是一个谎言。

有效市场假说，一个经济学学说，由尤金·法马（Eugene Fama）于1970年深化并提出的，是投资学中最重要的七个理念之一，其对有效市场的定义是：如果在一个证券市场中，价格完全反映了所有可以获得的讯息，那么就称这样的市场为有效市场。

至少也是一种非常有损的启发。

生活中最美好的事情往往发生在 EMH 之外的地方。

在许多情况下，把世界模拟成 500人其实要比80亿人更为准确。

Most people are other people。

我们知道的比我们想象的要少

危机重复发生并不反常。

我们相信的许多事情都是错误的。

我们经常问错问题。

你能做的比你想象的多

我们被看不见的正统观念束缚住了

但是物理定律才是唯一的限制。

禁止 micro-management 的文化是不好的。

伟大的个人应该有充分的权利来行使他们的判断力

我们的目标不是不犯错，而是在某些方面达到不相关的卓越水平

不好的一面是值得的

小队伍更好带。

更快的决定，更少的会议，更多的乐趣

没有必要因为政治原因而分工

平庸的人没有多少生存空间(也可以付更多!)

大型工程项目的解题智商比表面上看起来要高。

许多科技公司的员工人数是普通公司的2-10倍

你的多巴胺是从哪来的？

答案是可以预测你自己的行为

与其让你的想法得到验证，不如从改进你的想法中获得多巴胺

你可以从“让事情发生”中得到你想要的

推荐

Thank you, GitHub
