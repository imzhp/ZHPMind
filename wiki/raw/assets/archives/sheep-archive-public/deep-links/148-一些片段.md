## Page Text

- 2015

- 2015年4月，Airtable 推出了 API 和嵌入式数据库，为其街区开发框架奠定了基础。

- 2015年7月，Airtable 推出了 Airtable 表单，用于收集和组织数据。

- 2015年8月，Airtable 提供了添加到 Slack 选项，以整合 Airtable 和 Slack。

- 2015年12月，Airtable 重新设计了 iOS 应用程序，并将条形码作为一种新的字段类型引入。

- 2017

- 2017年飓风哈维袭击德克萨斯州和路易斯安那州时，Airtable 被用来记录获救宠物的日志，让它们与主人团聚。这一成功让 Airtable 轻松成为“独角兽”

- Howie 解释了 Blocks

- 这是一种在 Airtable 上运行的应用程序。目前，只有块开发的 Airtable 可用。最终，该平台将向第三方开发者开放。Howie 演示了一个 Maps Block，它使用来自 Airtable 的数据自动生成地图(可以显示活动地点等)。块可嵌入并显示最新数据。

- Howie 介绍了一个用于设计使用数据库信息的自定义打印布局的 Block，以及一个使用 Google 的 Cloud Vision API 来标记和描述图像的 Block。他确认了 Zappier 和 IFTTT 的整合。用户现在还不能直接将数据发送到 Airtable，但是 Zappier 集成使这成为可能。

- Howie 解释道，Blocks 可以让 Airtable 自动发送电子邮件和短信。例如，提醒员工第二天的工作时间表。

- Howie 解释了为什么 Airtable 应用程序商店目前仅限于 Airtable 内置的应用程序: 部分原因是为了建立质量标准。最终计划与第三方开发商分享收入。

- Howie 描述了 Airtable Universe: 一个类似 github 的公共存储库，用户可以在其中共享工作流模板。布局鼓励提交者解释他们的用例。
