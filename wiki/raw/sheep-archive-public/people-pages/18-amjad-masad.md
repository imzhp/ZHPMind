一位约旦裔美国企业家和工程师。他是世界领先的在线编程环境和社区 Replit 的创始人和首席执行官。在 Replit 之前，Amjad 在 Facebook 工作，监管 JavaScript 基础设施团队，并开发一些世界上最流行的开源开发工具。在此之前，他是世界领先的在线编码学校 Codecademy 的创始工程师。

计算机是人类历史上最强大的工具。可悲的是，大多数人只是这些机器的消费者。只有相对较少的人——专业的软件开发人员——能够最大限度地利用这种超能力。它创造了一个不平衡的世界，那里有程序员，还有那些被编程的人。这种情况类似于印刷机出现之前的识字情况，那时只有有权势的人才能接触到书籍和书面交流。印刷机的发明导致了民主、科学和工业革命，但是从创造到革命大约花了一个世纪，这意味着整整一代人在新的技能、观点、学习和交流方式下成长。Replit 将把下一个10亿的软件创造者带到网上，并将加速向软件和互联网真正成为“伟大均衡器”的世界的转变。不久之后，任何人，无论地位或经济状况如何，都将能够在互联网上创造软件和财富。如果我们成功了，任何愿意学习并产生好想法的人都会变得富有。

在创建 Replit 之前，我是 Facebook JavaScript 基础设施团队(我帮助创建的)的技术主管。我们构建并维护了开源工具，这些工具使 JavaScript 开发更容易、更易访问，而且通常更好。我们构建和/或维护了诸如 Babeljs 编译器、 Jest 和 React Nativepackager 之类的东西。这个团队的一些形式仍然是强大的，现在正在做甚至更令人惊讶的事情，如纱包经理。

在那之前，我是 Codecademy 的一号员工。我做了一些技术领先的，建造的产品和基础设施。在一家高增长的消费者初创企业中，尽管经历了压缩，但仍是一次很棒的学习经历。在此之前，我曾短暂地在雅虎(Yahoo)工作过。在那之前，我上了大学，兼职做网络安全工作。

至于工作以外的事情，我喜欢举重和烤牛排。我也喜欢阅读，主要对心灵哲学和人工智能感兴趣。理解和潜在地模拟大脑是我小时候对计算机感兴趣的原因。我还对传统和古人类学感兴趣。现代世界有很多美好的东西，但是当我们想要过一种充实而健康的生活时，我们也有很多需要去追求的东西。我认为过去比人们愿意承认的更有智慧。
