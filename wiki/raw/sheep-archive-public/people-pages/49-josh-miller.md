我们拥有世界上最复杂的搜索算法，但仍然没有清晰的模拟“互联网的 GPS”或“互联网的指南针”到底是什么样子。谷歌搜索相当于神谕/精灵。是的，我的愿望是你的命令，但是如果我不知道我到底需要什么或者去哪里呢？需要更多的导航推荐算法。

这里可以做的事情太多了，我以前在信息森林里已经讲过了，但是我认为自从我写了这个以后，我的思维已经发生了变化。我不认为这是一个公司的工作。就像操作系统一样，我们应该有一大堆微小的、集中的工具，它们可以协同工作，让网络看起来更像一个你可以随便逛逛的城市，而不是“一堆网站”。

这份思考同样适用于做出 Arc 的 The browser company。

以下为 LUXU 的正文：

一股重新改造浏览器的妖风又刮起来了

解决方案

当我们想到在互联网上浏览，我们常常忽略浏览器本身，我们更多想到的是哪些能够在线做的事情——例如我们阅读的文章、我们发送的邮件、我们看的节目，所有这一切都是通过应用或是软件做到，浏览器，则因为它太过普适而被忽略。

尽管我们的互联网使用方式已经演变，浏览器仍然相对保持不变。虽然我们所有其他软件工具都在变得更好——具有更多的协作功能、灵活的界面和强大的功能——但浏览器基本上仍只能达到25年前的功能水平。

更重要的是，我们常常嫌弃浏览器的各种缺点。当我们的浏览器有大量的标签时，我们觉得自己效率低下：当我们在浏览过程中失去专注力时，我们觉得应该需要更多的约束，当我们找不到网址时，我们认为一切都杂乱无章。为什么浏览器可以豁免？

这就是为什么我们正在建立一个新的浏览器——我们相信它可以做更多的工作来增强我们的能力。我们正在想象一个浏览器，可以像我们一样快速思考，把生产力解放出来，把我们的创造力向前推进。让它真正像2020年浏览器该有的样子，并且作为一个我们通向未来的基础。

观点

细节

BC 的浏览器叫做 Arc Browser，根据能够检索到的截图，可以看到它大概去掉了传统浏览器的所有操作相关的界面元素。

BC 的 CEO Josh Miller 把浏览器看做是操作系统，他把 Arc 比喻为在Web 上的iOS，这个浏览器通过你浏览的网站个性化定制你的 News Feed，所有的 Web app 如果都像是一个原生的 App，浏览器只是一个 App Launcher 会是怎样的？如果你从一个 Tab 拖动文件到另一个 Tab，它会如何响应？如果浏览器本身就可以分享、同步、兼容多人体验……

在同一赛道上的有：

Mighty ：基于 Chromium，声称减低十倍的内存占用，为速度而生，并且它会利用云计算加速浏览体验。

Brave：主要功能是阻止跟踪，借助 Tor 洋葱网络提高浏览隐私，优化了 Chromium 的性能，Brave 开创了观看广告的新模式，它创建了代币功能，用户可以通过 Brave Reward 主动浏览广告换取代币，并兑换优质内容和礼品卡

Synth：该浏览器建立了一套新的书签体系，让浏览像是使用 Inbox 的体验，更多的特色是把 Web app 组织工作流。

Sidekick：提供了一个竖向的 App Launcher，让 Tab 更容易进行组织，

Miller 说：

"We don't need a new web browser, we need a new successor to the web browser."

BC在 2019年创立，时任奥巴马任职时担任白宫的产品总监的他，收到当时担任他上司的 Jason Goldman 的启发：平台拥有撬动一切的力量，如果真的关注未来的互联网，或是我们我们使用电脑的方式，或是要打破和提升技术，那就不要做应用，要去做平台，像是iOS Windows Android 和 MacOS。

Miller提到像是 Figma, Notion ,Airtable 还有 Superhuman 这样的公司并没有首先去开发移动端或是桌面端应用，而是优先使用 Web 技术，他认为原生应用只是 Web app 的一层皮，只是外增了桌面 Icon 而已。

Miller确信下一个大平台就在他面前：开放的网络。基础基础设施工作， 应用程序是伟大的， 没有科技巨头的方式强加规则和提取巨额佣金。唯一缺少的是一个工具，以用户友好的方式将这一切聚集在一起，使网络超过其部分的总和。

当然，工具不存在是有原因的。一般来说，互联网用户使用两个浏览器之一：一个来自他们的设备或谷歌Chrome浏览器。Chrome 拥有约三分之二的浏览器市场，并持续增长，而其竞争对手都拥有个位数的份额，而且大多数继续萎缩。许多用户抱怨Chrome的性能问题和谷歌的大规模数据收集，但Chrome实际上赢得了浏览器市场。其他浏览器现在使用 Chrome 的基础引擎铬，并复制其界面，因为这是每个人都知道的。

具有讽刺意味的是，Chrome 也是为确切的未来浏览器想象而设计的。"我们意识到，网络已经从主要简单的文本页面发展到丰富的互动应用程序，我们需要彻底重新思考浏览器，"Sundar Pichai在2008年宣布Chrome的博客文章中写道。"我们真正需要的不仅仅是浏览器，还有网页和应用程序的现代平台，这就是我们着手构建的。

但谷歌在Chrome开发过程中做出了一个关键的决定。它构建了 Chrome 来摆脱困境。"对大多数人来说，重要的不是浏览器，"Pichai在2008年写道。它只是运行重要内容的工具——构成网络的页面、网站和应用程序。即使谷歌推出了Chrome操作系统，它也只是将这款偏向浏览器移植到轻量级的桌面操作系统上。 谷歌构建了20年前想象中的浏览器Netscape的近乎完美的版本，但它并没有重塑任何东西。

Agrawal 说："标签仍然是标签，书签仍然是书签，历史仍然是历史。"20 年来，UI 并没有真正改变，[然而]我们每天花 8 个小时在它前面，完成工作是必要的。当他和 Miller 在2019年开始集思广益为他们的新项目出谋划策时，他们并不知道他们计划如何改变这一切。但他们相信，浏览器市场是如此广阔，如此成熟的创新，这是值得采取甚至有点曲折的路线，找出答案。"没有人认为他们需要一个新的浏览器，"Mozilla 前首席执行官、浏览器公司投资者John Lilly 来说。"所以你必须做一件不同的事情。

无法免俗

经过几个月的头脑风暴和原型，浏览器决定击败Chrome的第一种方法只是建立一个浏览器，这是更好的使用。他们叫它 Arc。Agrawal 很早就决定不尝试重建整个浏览器Stack，并像其他人一样以 Chrome 为基础。相反，浏览器的团队花时间思考如何解决标签超载之类的问题，那种在屏幕顶部的小图标海洋中找不到任何东西的熟悉感觉。

这是团队的设计师Nate Parrott长久以来一直在思考的问题。"在我遇见 Josh 之前，"他说，"我对浏览器非常着迷，因为这是你体验这么多网络的窗口，但感觉好像没有人在网络浏览器上工作。除了在 Snap 的日常工作之外，他还正在构建一个具有一些新互动想法的 Web 浏览器。"对我来说，一个重要的是，我想摆脱打开和关闭标签之间的区别，"他说。"我想鼓励标签囤积行为，在那里您可以打开尽可能多的标签，并组织它们，这样您就不会经常不堪重负地同时看到它们。

Parrott 把这种想法带到了浏览器公司。Arc 最直接的功能之一是它结合了书签和标签。单击侧边栏中的图标会打开应用程序，就像在 iOS 或 Android 上一样。当用户在其他地方导航时，他们不必关闭选项卡：它只是在后台等待，直到它需要再次，和Arc管理其背景性能，所以它不会使用太多的内存。用户不是在选项卡中打开 Gmail，而是直接打开 Gmail。

目前 Arc 已经有上百人参与封闭内测，Miller 现在对 Arc 的公开态度非常保守，生怕大厂直接 Copy 了过去。目前它们公司内部就是不断的制作原型，快速验证各种想法，从建立到测试，一步一步，看看会发生什么，它们有参考 Chrome 的一些特性，但要实现这么完善的功能就必须不断的重复构建和测试。总之 BC 现在就是一个创业公司的基础阶段，仍有许多问题面临。

浏览器的未来

Miller 和他的团队有许多的想法，但很多想法只是猜测，他说到我们如果要做好 Arc 就要不断的把它呈现在人们面前，看看大家对 Arc 的反应是怎样的。

有一个 Hit 功能是 Notes App，它甚至不是一个应用，用户打开一个空页面时，它会是一个空页面，是一个 Notion 笔记， Miller 喜欢苹果笔记，但如果复刻它实在是太荒谬。

大家似乎对于浏览器都有疯狂的想法， Krist 有一个操作系统想法叫做 IOMess，是一个混乱的生活操作系统，可以帮助人们看到前妻的照片并且发送酒醉诳语，Parrott 考虑从网络上拼凑一个通用 Inbox，并且考虑完全不受骚扰的浏览器会是什么样子。Miller 似乎真的想建立一个从本地上传文件的服务……团队几乎支持任何想法

这种风险在于，浏览器会变成一个研发商店，虽然充满各种想法，但是人们并不会都去使用。

人们登录Arc，给他拥有整个周期生命的应用程序，把文件、共享列表一切都呈现给它们，一切都在线，一切都同步，一切都是 URL。

对 Miller 来说，最棘手的是原生的开发者工具，API 和快速进行想法验证的微应用，Miller 提到搜索许可、免费增值订阅、企业版和广告的可能性，但还为时尚早，

然而，对浏览器和科技行业的其他成员来说，这些可能性似乎值得冒险。使用网络浏览器的人比使用 Facebook 或 Google 的人多，现代生活的大部分发生在窗口和标签中。已经超过25年没有人从根本上重新思考什么是浏览器。开放式网络即将卷土重来，网络浏览器也是如此。如果任何能够推翻Chrome，它可能有助于定义未来20年的生活是什么样子。

美国当代艺术家 James Turrell 是 Josh Miller 的朋友，James Turrell 最知名的作品是仍在持续进行创作中的“罗丹火山口”（Roden Crater），他将一个死火山的喷火口改造成为可用肉眼观测的天文台，专为欣赏天空上的各种自然现象而设计。他的作品挑战人们快速观看艺术作品的习惯。他认为观者在一件艺术作品上花费的观看时间太短，以致于无法认真欣赏作品本身。

James Turrell

我觉得我的作品是为了一个人、一个个体而创作。你可以说那个人就是我，但这并不是事实。这是给一个理想中的观赏者。有时候在观看某些东西的时候，我会有点急躁。当蒙娜丽莎在洛杉矶展出时，我只看了13秒。但是，你知道的，现在有一个慢食运动。或许我们可以来个慢艺术运动，花一个小时（来欣赏作品）。

在过去几年，有幸认识了 James Turrell  先生，他经常谈到“彩色光”作为他的材料和工艺。互联网似乎也认同这一点。然而，当 James Turrell  先生把他的作品简化为“彩色光”时，他在这些时刻表现出了(可爱的)谦逊正如他解释的那样，其意图要深刻得多。

James Turrell  作品

重要的是洞察力。对我来说，它是利用光作为一种材料来影响感知的媒介。我觉得我想把光作为一种神奇的长生不老药，我们通过皮肤摄取维生素 D，我的意思是，我们确实是吃光的人，然后影响我们看东西的方式。我们生活在我们创造的现实之中，我们完全不知道我们是如何创造现实的。

这是如何在艺术中体现出来的呢?

在直岛，一位参观 James Turrell  作品的游客讲述了他们的经历。

警卫在入口处没收所有人的手机。他带我们穿过走廊，走廊是如此的黑暗，以至于我们的眼睛感觉是闭着的。墙壁对手是冰冷的。在安藤忠雄的极简主义建筑中，你的眼睛会适应 James Turrell  的《月球的背面》。像 James Turrell  的所有作品一样，《月球的背面》是一部“探索光与空间的作品，它无需言语就能与观众交流”。当你坐在寂静的黑暗中，所有的知觉都消散了，一个发光的标记出现了。它像你一样徘徊，在黑暗的空间里微弱地移动。当你走向它，一个看不见的空间在你面前打开，标记消失了。月亮的背面是可以体验的，而不是看到的。

月球的背面

本质上，James Turrell  先生讲的信息很简单。

光揭示了我们周围的世界，因此，也揭示了我们对它的感知。

塑造光明，塑造现实。

如果你仔细想想，现代软件就是彩色光。

从屏幕上照射出来的彩色光的模式支配着我们的日常生活。

事实上，软件的这种彩色光芒也越来越影响我们对现实的感知。

我第一次见到 James Turrell  先生时，他解释说人类就像甲壳类动物。

我们居住在贝壳里——汽车、住宅、办公室、餐馆——无意识地在它们之间移动，很少想到或质疑贝壳本身。

为了表示抗议 ，Turrell 先生的艺术作品挑战我们自己的贝壳。

要求我们在居住的时候感受到某种东西。

如果我们能够大胆一点，也许甚至可以重新想象整个贝壳。

在今天这个时代，我们在由软件构成的外壳中度过了无数时间。

单调的长方形盒子，从屏幕上投射出光芒。

当你打开你的网页浏览器时，你什么都感觉不到。

相反，如果我们的软件外壳是 Turrellian 的，它们会是什么样子?

它们会让我们有什么感觉？

当我第一次在 罗丹火山口 （Roden Crater ）看到日落时，我看到陌生人喜极而泣，惊奇地大笑。

简单来说，就是 James Turrell  所描述的“彩色光”。

每隔一段时间，我都会提醒自己，软件也只是彩色光。

一种“奇妙而神奇的长生不老药”，散发着改变我们对周围世界的看法的潜力——甚至可能重塑它。
