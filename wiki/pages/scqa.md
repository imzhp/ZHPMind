# SCQA 框架

## 定义

SCQA 是芭芭拉·明托（Barbara Minto）在 [[the-pyramid-principle]] 中提出的序言写作模板：**背景（Situation）→ 冲突（Complication）→ 疑问（Question）→ 回答（Answer）**。它的本质是讲故事：先在时间/空间中锚定读者，再用冲突激发疑问，最后给出文章将要回答的问题。

## 四个要素

**背景（Situation）**：读者已经认可或将会认可的、关于文章主题的无争议陈述。目的是把读者锚定在同一时空，开始故事。典型信号：读者点头说"是的，这我知道，那又怎样？"

**冲突（Complication）**：推动故事情节发展的因素——可以是意外、问题、变化或新认知，必须引发读者的疑问。冲突不一定是"坏事"，任何能打破背景平静状态的因素都算。

**疑问（Question）**：由冲突自然引发的读者问题，通常是以下四类之一：
- 应该做什么？（When in trouble, what to do?）
- 应该怎么做？
- 应该这样做吗？
- 为什么会发生？

**回答（Answer）**：文章的中心思想（金字塔顶端），即对疑问的直接答案。一个好的序言只能对应一个初始疑问。

## 四种顺序变体

| 名称 | 顺序 | 适用场景 |
|------|------|---------|
| 标准式 | S→C→A | 读者对背景熟悉，需要先建立共识 |
| 开门见山式 | A→S→C | 读者已知问题，只需直接给出立场 |
| 突出忧虑式 | C→S→A | 强调危机感，让读者先感受到紧迫 |
| 突出信心式 | Q→S→C→A | 读者高度关注，直接用疑问调动注意力 |

## 使用规则

1. **序言只包含读者已知信息**：不要在序言中引入读者可能质疑的新事实，那些内容属于正文
2. **序言长度由读者与主题决定**：对亲密的沟通对象可以只有一句话；公开报告可能需要 2–4 段
3. **冲突和疑问可以是隐含的**：尤其在商务备忘录中，读者通常能自行补全
4. **关键句要点同样需要引言**：每个一级论点下，也用简化版 SCQA 把读者带入新话题

## 典型模式

```
发出指示式：
  S = 我们计划做 X
  C = 需要你做 Y
  Q = （如何做 Y？—— 隐含）

请求支持式：
  S = 我们遇到了一个问题
  C = 我们的解决方案需要 N 元
  Q = 我应该批准吗？

解释做法式：
  S = 你们目前的系统是 X
  C = 该系统不能正常工作
  Q = 如何让它正常工作？

比较选择式：
  S = 我们希望做 X
  C = 我们有若干方案
  Q = 哪一种最合理？
```

## 与相关概念的关系

- SCQA 是 [[the-pyramid-principle]] 金字塔结构的入口机制，决定了整篇文章要回答的初始疑问
- 它也是界定问题框架的"可视面"——切入点/序幕对应 S，困扰/困惑对应 C，现状/目标差距对应 Q
- 与 [[critical-thinking-framework]] 中"清晰陈述论题与结论"的要求互补：批判性思维要求结论清晰，SCQA 提供了如何在篇首建立结论的叙事路径
