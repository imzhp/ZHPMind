# 亚马逊价格策略（Amazon Pricing Strategy）

价格是亚马逊运营里最被低估的杠杆。本页（嘉宾堂哥的反直觉方法论 + 乔的价格形式系统）是 [[amazon-inventory-replenishment|库存]]"备货决定定价权"的定价侧对偶——库存讲"涨价的前提是货不够"，本页讲"降价的衡量指标 + 何时该降何时该涨"，两节共构"库存-定价-广告"三角元层级。也是 [[amazon-profit-analysis|利润分析]] 秒杀节奏、[[amazon-patent-screening|专利]] 超额利润定价的接续页。

> 整节最反直觉金句：**衡量降价是否生效的唯一指标 = c-访问转化率，不是单量。**

## 螺旋：单次降价触发两轮自然增长

销量 = 曝光 × 点击率 × 转化率（套 GMV 万能公式）；价格变动只影响点击率和转化率，曝光短期不变。

- **单次价格调整可触发两轮自然增长**（反直觉）：50 → 85 单（第一轮点击率/转化率 1.3×1.3 = 1.69 倍）→ 110 单（第二轮关键词排名上升再 1.21 倍）。多数人以为降价只有一次性效果。
- **第三轮卡顿**：到 110 单后可能停滞（头部 3–6 名权重太稳），此时配合 7D + 广告再推 20–30 单。
- **失效条件 1：降幅太小**（$30→$28 数据噪音淹没信号；讲师直接定到成本价或 5% 毛利）。
- **失效条件 2：基础单量 <20 单**（5×1.69 = 8 单颗粒度太小，无正向反馈）→ **新品禁螺旋**。

## 新品测款：4 价格档 + 财务接受度

- **4 价格档分配 200 套库存**：市场均价 30 套 + 低于均价 50 套 + 成本价 50 套 + 亏本价剩余；分别测点击率/转化率服务财务模型。
- **一单亏损成本 ÷ 投入成本 = 回本周期**：亏损占比越高 → 越长不赚钱 → 风险积累（变狗/封店）。**财务接受度**是测款决策核心，而非"亏不亏"。
- 亏本价一般不测（成本价数据 OK 就停，否则类目过卷需放弃）。讲师亲案例：40 美金转化率 3% → 28 美金转化率 20%（下探 30% 客单价 → 转化率 6.6 倍）——**价格 ≠ 单一变量**。

## 老品螺旋的反直觉：降价 + 缩广告

讲师 5.8 万/月案例。死局：广告 600 美金/日烧一个月，关键词只升 1 位，11 月初查 ERP 亏 3 万。

- **关键调整：35% 毛利 → 0% 毛利 + 广告 600 → 200 → 100 → 70 美金/日**（⭐⭐⭐ 反直觉：**广告也要缩，不是只降价不动广告**，同步调两个变量）。
- 预期 vs 实际：运营按"广告减少 = 单量减少"算 100→30-40 单，实际 100→80→90→100→120→130（8–9 天翻倍）——**自然单暴涨抵消并超过广告单损失**。
- 结果：净利 18/单 × 4000 单/月 − 广告 1.4 万 = 净利 5.8 万/月（原状态盈亏平衡）。**钱花得更少，赚得更多**。
- **元层级金句**：广告暴拉 vs 降价缩广告，后者从效率角度更优——"一天烧 1000 美金亏 5 万 vs 一天烧 100 美金亏 5000"，后者自然单进得快。多数人推产品的死胡同就是"加广告解决一切"。

## 上调节奏 + 限购 + 螺旋三前提

- **上调节奏**：0.5–1 美金/3–7 天（<$20 客单价）或 5% 幅度；**销量降 >15% 立即调回**，猥琐发育一周再试。
- **限购的妙用**（反直觉，整门课首次出现"限购作为运营杠杆"）：成本价螺旋时，成本价单是亏的，不希望卖太快 → 限购既达成螺旋目的又让库存健康。
- **螺旋三前提**：基础单量 + 财务接受度（亏多少算清，中途不变卦）+ 备货提前一个月（与 [[amazon-inventory-replenishment]] 互证）。

## 5 种价格形式系统

- **划线价**：亚马逊取参考价（虚拟价，不公开）做划线；**养划线价的标准动作 = 新品大额 Coupon**（降低参考价）。
- **Coupon 不影响亚马逊价格体系 → 可养秒杀**（反直觉）：开 Coupon → 拿划线价 + 30 天最低价的 85% 自动满足秒杀条件。<$30 用 %，≥$30 用金额（更刺激），降幅 >50% 一律用 %。
- **Prime 专享 Coupon = 隐藏式降价**（反直觉）：非 Prime 用户看不到 → 前台显示原价 → 竞卖看不到降价信号 → 避免互相跟杀。
- Promotion 老带新（爆款 A 给新品 B 引流建关联流量）；Multi-pack 折扣（复购品类）+ 社交媒体促销码。

## 秒杀实操对比 + 防御性 7D

| 秒杀 | 特征 |
|---|---|
| **LD** | 一周一次 $150（黑五翻倍），进度条 + 抢购心理，适合 Q4 大旺季冲量；平时不报（效果差+贵） |
| **7D** | 一月两次免费 + 平时最优；进度条不显示，前 3 天平淡、4–6 天最猛；7D 前 3 天养价格让当周叠加 |
| **PD** | 仅 Prime + 免费 + **可提价报**（参考价机制不严）；利润导向旺季秒杀，黑五对二线产品最划算 |
| DOTD | LD 升级版，全年最低价 ×0.8，需客户经理报，小卖家拿不到 |

没基地找服务商 $70/次（有黑名单风险，偶用 OK）。**头部产品防御性 7D**（⭐⭐⭐ 反直觉）：已到天花板还做 7D，因为**头部护城河 = 流量 ≠ 产品力**；不定期压制新卖家起势期，流量不被蚕食。

## 定价 5 因素 + 标品/非标品价格弹性

- **定价 5 因素**：毛利率 / 竞争优势（比竞品便宜 $1 抢 A 层位）/ 高转化率（渗透定价）/ 市场需求 / 标品 vs 非标品。
- **渗透定价法 = 螺旋打法的经济学名词**（反对"内卷"叙事：降价 → 单量翻倍 → 后期提价回利润 ≠ 内卷；内卷是降价后单量不动且不能恢复）。
- **季节性产品 Q4 敢于涨价**（反直觉）：平时 $13.99 卖 50 单 → Q4 $23.99 卖三四百单。多数人 Q4 想冲量降价，实际**Q4 是收割利润非冲量**。
- **标品 vs 非标品价格弹性差异**：标品（碗/T 恤/衣架）弹性大 → 降价直接有效；**非标品（审美/款式驱动）弹性小**（鸟图案 $19 卖不过大象图案 $25）。蓝海产品不需降价（头部就卖 10 单，降价没意义）。

## 不同阶段降价目的不同（降价是战略性决策）

- **衰退期降价 = 清库存**（不考虑坑产/转化率，只求回笼资金，呼应 SKU 四象限 D 级处理）。
- **成熟期降价 = 防御新品冲击（定期 7D）**——整门课首次明确"成熟期降价不是出错，是战略"。
- **推广期降价 = 换流量**（广告投入产出比恶化时降价更划算，呼应 [[amazon-ppc-advertising]] 路径 A/B）。
- **降价是战略性决策，不是拍脑袋**：多数人死循环（单量不好降价 → 利润不好涨价 → 单量回原 → 降价 → 无限循环），根因是目的不明确。正解：每次降价前算清亏多少、要什么结果，中途不变卦。

## 衡量指标 = c-访问转化率（整节最反直觉）

- **衡量降价是否生效的唯一指标 = c-访问转化率，不是单量**（⭐⭐⭐）：单量受曝光+点击率+转化率三向影响，变量不纯；转化率受价格影响，是纯净信号。
- 短期降价不提升曝光 → 7D 结束单量回原是常见反例（多数人以为 7D 做完产品就上去了）。
- 长期降价 → 数据增长 → 排序优先级 → 曝光基数（降价有效时长不能太短 + 不能中途变卦，最少一周 c-转化率持续增长才算生效）。
- c-转化率 vs c-访问量：c-访问量受曝光影响（变量不纯），c-转化率受价格影响（纯净）；前提是竞卖不集体降价（否则市场均价拉低，你的转化率也被稀释）。
