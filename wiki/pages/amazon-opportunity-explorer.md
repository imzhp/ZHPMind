# 亚马逊商机探测器与推广成本预估（Amazon Opportunity Explorer）

这是整门课的**工具操作底层**。之前每节都引用"预估"这个动作（[[amazon-new-product-launch|11.9 真实案例]] 8 项指标怎么估、市场容量怎么算、价格策略下转化率怎么知道），本页才告诉你怎么做——首次用亚马逊后台原生数据（商机探测器 = 亚马逊内部数据开放）+ SIFT 流量时光机 + 产品开发表。与 [[amazon-keyword-library|SIFT 反查关键词]] 是姊妹工具（一个反查关键词，一个反查细分市场，数据来自亚马逊内部更准）。

## 商机探测器结构与细分市场聚合

进入路径：增长 → 商机探测器 → 三入口（分类/关键词/ASIN）。

- **细分市场 = 特定买家需求的一系列搜索词 + 商品的耦合**（不是单维度）。
- **关键词聚合 = 搜索后点击/购买的商品重叠度（不是文本相似度）**（反直觉）：6 个词搜了都点击/购买商品 A → 6 个词组成一个细分市场。聚合的因变量是商品，自变量是搜索行为。
- 细分市场命名 = 该组关键词中最高频词（Storage Bins 是收纳箱类目最高频词）。

## 改版后的数据底层（不搞清后面全用错）

- **搜索量从"24h IP 去重"改为"一天内输入所有次数"**（⭐⭐⭐ 工具数据最关键变化）：老版搜 3 次记 1 次，新版记 3 次 + 翻页再 +1 → **改版后搜索量 = 老版 × 3–5 倍**。
- **转化率被稀释 3–5 倍**：分母从"搜索人数"变"搜索次数" → 统计上必然下降 → **不能跟改版前的转化率绝对值比较**。

## 细分市场指标：活跃商品数才是真竞争对手

- **平均售出商品数 = 搜索后直接购买**（不算关联/跳转购买，只算直接漏斗）。
- **点击量最多的商品数 = 90% 点击/购买的活跃商品数**——剩 10% 是零星出单（30 天才 4–5 单）。**活跃商品数才是真正的竞争对手数，不是搜索结果数**（反直觉：以前看 1 万搜索结果，实际只有 100 个有销量）。
- **总销量倒推公式：`平均售出 × 活跃商品数 ÷ 20%–40%`**（搜索购买只占总购买 20–40%，剩下是复购/关联/跳转）。
- 判读反直觉：Storage Bins 搜索量 3071 万 + 活跃商品 102 = 头部集中（非红海，大市场但活跃卖家少）；反例 1/6 搜索量 + 400+ 活跃卖家 = 大红海（需求 < 供给 → 内卷 + 转化率低）。

## 商品页卡 = 全系搜索报告（反向工程窥竞品）

- **商品页卡点击次数 = 后台全系商品搜索报告点击量**（亲案例 1844 vs 1844 完全一致）：以前只能看自己 ASIN，现在能看**任何竞品**的搜索点击数（竞品情报反垄断）。
- **搜索流量占比 20–40%**（亲案例 1844/5636 = 32.7%）（反直觉，不是 50/50）：剩下来自详情页流量（关联/广告位/推荐位）。标品（勺子）路径短 → 搜索流量占比偏高；非标品（审美驱动）路径长 → 偏低。
- PV 转化率反推：大类排名 → 销量 + 商品页卡 7 天搜索点击数（关键约束：7 天预估销量要扣关联流量，只算搜索层 ≈ 总销量 × 20–40%）。
- **搜索转化率 × 1.2 = 广告转化率（新品期）**：广告位优于自然位 + 词经过精调 → 广告转化率高 20%；成熟期趋同。

## 搜索转化率：衡量市场供求的唯一指标

- **3 层漏斗（展现→点击→购买）+ 4 种转化率**（session/PV/广告点击/商机搜索）不能直接比较。
- **搜索转化率（展现/购买）= 衡量市场供求关系的唯一指标**（第一性原理：一次搜索可产生 N 次点击，市场角度只能用搜索量为分母；点击转化率只衡量单品竞争力）。
- **搜索转化率高 ≠ 蓝海**（⭐⭐⭐ 整节最大反直觉）：低客单刚需标品（勺子/碗/塑料袋）搜索转化率高，但 CPC 高竞争激烈 → 高转化 ≠ 好做。**iPad 保护壳案例**：转化率 30% + CPC $4-6 + 客单价 $9.99 → ACoS 100% 还降不下来（市场决定的死结，呼应 [[amazon-ppc-advertising]] 整体盈亏 ACoS）。
- **绝对值无意义，相对值有意义**：某类目 8% 转化率不知好坏，但同类目不同细分市场 3% vs 2% vs 1% 比较有意义。同细分市场不同关键词转化率差异（storage box 0.1% / three bins with lids 0.6%，6 倍）→ 陌生市场用相对差异决定投放重点。

## 洞察 + 趋势：垄断度 / 新品活跃度 / 双峰季节性

- **前 5 / 前 20 品牌点击份额 = 垄断度最佳指标**（亚马逊内部数据）：Storage Bins 前 5 品牌 40% = 中等垄断 + 容量大可忍受；蓝海小市场前 5 品牌 80–90% 正常。与 [[amazon-product-selection]] 5 种垄断分型三角互证。
- **成功发布商品数 = 新品活跃度**（30 天年化 5 万美金 = 一天 7 单算成功新品，很难达到）：180/360 天成功新品占比 → 市场是否欢迎新品。
- **商品数趋势判读**：商品数↑ + 搜索量↓ = 衰退期（内卷加剧）；同向才健康。
- **双峰季节性**（反直觉）：搜索量峰 + 转化率峰双双攀升 = 真旺季。Prime Day/黑五的搜索量峰是**平台流量波动 ≠ 类目旺季**；玩具 11 月双峰才是真旺季（销量 ×4）。

## 推广成本预估：CPA + 广告订单占比

两核心数据 = **CPA + 广告订单占比**。工具：SIFT 流量时光机（广告占比）+ 商机探测器（广告转化率）+ 后台广告创建（CPC 区间）。

**CPC 三估法**：
1. 全新品看推荐竞价取**区间高值**（不是中值；新品期出价偏高才有较好曝光）。**CPC 加权平均**：大词 1.5 + 关联词 1.1 + ASIN 定投 0.5 + 自动 0.5 → 加权 1.1（低竞价的自动/ASIN 定投拉低均值）。
2. 垂直类目拓品（内部数据完备，根本不用估，最高成功率路径）。
3. 服务商内部数据（店铺 CPC 报告 2000+ 一份，垂直类目分摊到多 SKU 划算）。

- **广告转化率长期 ≈ 自然转化率**（⭐⭐⭐ 整节最深）：因为产品转化率由产品力决定，Review 数 + 广告优质性短期影响有限。
- **卡 top 不可扩量**：小预算可稳定卡 top + 高转化；一旦扩量必打详情页/中部位置 → 总体转化率回归大盘自然值。

## SIFT 流量时光机 + 盈亏平衡周期

- **SIFT 旗舰版核心 = 广告流量 vs 自然流量曲线**（爬虫爬关键词位置 → 算法出占比曲线）。新品正常曲线：广告流量明显高于自然，**拐点 = 自然流量超过广告流量**（如第十周拐点 → 进入盈利期）。
- **SIFT 误差点**（反直觉）：腰部产品/非标品广告位多在详情页 → 爬虫只能爬关键词广告排名 → **显示广告占比 10%，实际 20%**。
- **盈利周期 vs 回本周期**（反直觉）：开始盈利只是不亏，回本要再等同样时间（账面利润弥补前期亏损，2 个月 vs 4 个月）。
- 盈亏平衡公式：广告占比 X 使毛利总额 = CPA × 广告单数（案例：售价 $23.99 / 毛利 7.67 / CPA 12.86 → 广告每单亏 5.2 → 盈亏平衡需广告占比 60%）。

## 产品开发表 + 终极判据：转化率 vs 大盘

- 表格字段：标黄（手填：售价/采购成本/实重/配送费/CPC/转化率/头程/汇率/包装尺寸）；标蓝（公式：FBA/投成/毛利/净利/ROI/CPA/周转次数/年 ROI）。
- **走美森 vs 走普船年 ROI 相同**：毛利差 4% 由周转次数补偿（周转次数是单单毛利的等效杠杆，与 [[amazon-inventory-replenishment]] 多批次出货互证）。头程 6 种（空运/快递/美森/卡航/普船/AGL），重货走方按 AGL。
- 六个月广告依赖衰减表：第 1 月 80% / 2 月 70% / 3 月 65% / 4-5 月 55% / 6 月 35% 才开始挣钱。
- **终极判据：转化率 vs 大盘**（⭐⭐⭐ 整门课选品最高位金句）：
  - 转化率 > 大盘 = **好产品**（上去稳得住，不需广告维持）
  - 转化率 ≈ 大盘 = 一般产品（花钱多能推起来）
  - 转化率 < 大盘 = **垃圾产品**（永远推不起来，关键词排名永远靠广告维持）
- **反对"必须做"**：200 万做 3C / 500 万做大件家具都做不起来 = 资源匹配不上换类目。类目"存在即合理"，问题在资源匹配不在类目本身（与 [[amazon-pricing-strategy]] 5 因素 + 选品本质贯通）。

> 元层级金句："毛利率正 → 控好广告就挣钱"——没有刷单的话，产品挣钱的核心 = 谁的广告花费控制得好。
