# 亚马逊新品推广全流程（Amazon New Product Launch）

这是云飞扬课程的 **SOP 集大成节**——把[[amazon-product-selection|选品]]（2）+ 关键词词库（7）+ [[amazon-ppc-advertising|广告架构]]（8）+ [[amazon-traffic-sources|流量分类]]（9）+ 优化诊断（10）串联成一条可复制的新品推广流水线，并用一个真实案例验证了方法论的**可预测性**。

> 元层级金句（整门课最高位）：**让产品适应你的标准，不是你的标准适应产品。** 这与选品的"运营可复制，产品不可复制"是同一哲学的两面。

## 新品立项：三件闭环

立项输出 = **财务模型 + 词库 + 竞品拆解**，三件缺一不可，缺任何一件后续都走不下去：

- **纵向词库分层**：全词库扫出不相关词 → 否词库；ABA 靠后 → 长尾词库；ABA 靠前 → 核心词库。
- **横向流量入口分析**：用流量时光机/ABA 看不同时间段长尾词起伏，抢独特时点词。
- **竞品运营打法拆解四件套**：价格策略 / 广告策略 / 站外策略 / 是否违规——拆完才能定推广策略。
- **产品开发表补齐财务模型**（推广成本预估是立项必交，对应选品的财务模型三角）。

## 推广前的逻辑：PPC 推自然排名

- **不刷单的话，PPC 是最佳拓流量方法**（原则上刷单 > PPC > 站外放量，但不刷单时 PPC 是极限选择）。
- **新品期主要靠广告推自然排名**：精准词投放 → 订单递增 → 相关性提高 → 自然排名往前。
- 元层级：所有推广动作都为一个目标——**有限预算拿最多点击和订单 = 加速数据量积累**。

## 页面优化（到货前一周必须完成）

- **QA 从 review 分析反推**：好评点 = 卖点变 QA；差评点 = 改进点变 QA（与词根分析同源）。可用 ChatGPT 角色法批量做。
- 红人关联视频：review 上方 5 个位置不铺满会被竞品视频填充 → 流量外溢。
- 时间节点必须卡准：货到才动手 = 推广节奏乱。

## 定价

- **一般 20% 毛利做新品推广**（空间不够则预算受限、快不起来）。直降优于 Coupon（Coupon 0.6 美金手续费 + 领取率不高）。
- **反直觉：新品期低价无意义。** 没有基础流量时低价启动不了流量；低价是有基础流量后的**转化引导工具**，不是流量启动工具。
- 秒杀/Coupon 要提前作为推广成本计入全期预算。

## 推广目标拆解

- **三类参考数据（优先级从高到低）**：现有类目数据 / 买竞品报告 / 自己预估。
- 三目标：销量 / 流量 / 绩效（ACoS + TACoS）。
- **整体盈亏 ACoS 作为目标 ACoS 上限**：新品期只要整体不亏即可，不要起步就追求广告本身盈利。
- 复盘价值：预估 vs 实际差距 → 多推几次后脑内演练越来越准（11.10 可预测性的根）。

## 投放评级 A/B/C/D

把流量 × CPA 四象限 SOP 化成评级表：

- **新品期优先 A、B；无 A 只投 B**（红海产品常无 A 词，很多人卡在这里不走）。
- 评级维度优先级：**相关性 > CPC（成本）> 流量**。
- ASIN 和自动投放也评级。**用 VLOOKUP 三表（词库 + ABA + 关键词表现）生成评级表**，助理看表即可投放。

## 广告架构（可伸缩）

- 3–5 个核心词各开广泛 + 精准两组活动（4–8 个 SP 关键词层活动）。
- **SBV 单独一组，且与 SP 广告位可共存**——同一关键词可同时布 SP + SBV 两个位置（呼应首页 4–5 次曝光）。注意 **SBV 半屏露出 = 空间占比**（移动端 60%+ 流量，SBV 在 APP 占屏一半），与 SD 的 VCPM 半屏 1–1.5 秒（时间定义）是不同概念，易混。
- 10–30 个 ASIN 中低竞价（CPC 比关键词低 30–40%），第二月选表现佳者加高竞价卡 TOP 拓词。
- **自动广告必开**（反直觉：词确定了仍要开）：跑收录 + 扫流量死角，抓每月偶发的个性化表达词，前置否定后继续优化。
- 整体预算 200–400 美金/天可伸缩（预算少可去 SBV/自动/减 ASIN 数量）。

## 真实案例：方法论可预测性验证

案例产品：客单价 45.99 / 毛利 22% / 备 1000 个（主推 SKU 500）/ 红海家居。整体盈亏 ACoS = 22%÷75% = 29.33% 定为目标。架构取舍：13 词 → 4 核心词各广泛+精准 + 5 长尾广泛一组 + 2 组 ASIN + 自动。

**8 项指标预估 vs 实际（全接近）**：CVR 5.7%(估 5.5) / 广告 CVR 6.11%(7) / CPC 1.16(1.2) / ACoS 36.38%(43) / TACoS 19%(32) / 广告占比 62%(75) / DMS 19.35(15)。**这是云飞扬方法论"可预测性"首次被验证**——预估偏保守的实际都偏好，说明保守预估预留了安全边际。CPC 两周从 1.48 降到 1.08（非常规速度，因点击量给足 → 相关性快速积累）。

**关键操作：推广全程只动竞价，不动投放和预算**（与"架构只为控制"贯通——架构设定后优化只在竞价轴上）。

## 元层级决策哲学：让产品适应你的标准

- **测款数据不符财务模型 → 直接 pass**（反直觉：不是"调广告技巧挑品子"，是"换品"）。
- 不要追求"神奇广告技巧"化腐朽为神奇。
- 云飞扬自己点明课程设计逻辑：**"财务模型这节课为什么放第一节？后面推广是否顺利取决于前面这个模型。"** 选品 → 财务模型 → 推广是单向依赖链。
- pass-或-推临界：偏离大 = pass；接近但不符 = 增资源继续推（提高容忍度/多亏，判断推上去后能否接受）。

## 答疑要点

- **PD/秒杀调整：只调竞价 + 预算，不调投放**（两天不足以判断投放变更）。
- 升级款决策：影响评分/利润 → new model 替代；不影响 → 1.0 + 2.0 共推（以护城河判断，不为升级而升级）。
- **高低竞价分层 = 流量分层**：低价主打 PP/关联，高价主打 TOS/搜索，两者都保留不关。
- 新广告没曝光 = 一定是竞价问题（前提 listing 和词没问题）。
