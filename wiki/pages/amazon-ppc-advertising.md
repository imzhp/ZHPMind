# 亚马逊 PPC 广告（Amazon PPC Advertising）

PPC（Pay-Per-Click，按点击付费）广告是亚马逊站内最重要的付费流量工具，也是[[a9-algorithm|A9 算法]]中关键词排名的加速器。核心认知：

> **广告只能锦上添花，不会雪中送炭。** 广告是动态的，好的打法是测试出来的，不是模仿出来的。

广告的根基是[[listing-optimization|Listing 质量]]——Listing 基础不牢，再高的 Bid 也无法获得好的转化率和广告质量得分。

## 广告的九大核心作用

1. 提升关键词排名（累积出单量）
2. 开发产品、增加变体测试
3. 快速获取流量入口
4. 提升品牌知名度
5. 新品测款
6. 增加账号安全等级
7. 指导爆款运作方式（发现哪些词转化好）
8. 检测 Listing 是否被 A9 收录（没有曝光 = 没有收录）
9. 增加用户对品牌的心理暗示

## 三种主要广告类型

### SP 广告（Sponsored Products，商品推广广告）

- 最主要的广告形式，有自动（Auto）和手动（Manual）两种
- **直接助推关键词排名**，出单累积对自然排名有实质影响
- 投放位置：TOS（搜索结果顶部）、Rest of Search（其他搜索位置）、Product Pages（商品页面）

### SB / SBV 广告（Sponsored Brands / Sponsored Brands Video，品牌广告）

- 定位品牌曝光，ACOS 通常较高
- **不助推关键词权重**（链接不带关键词参数，逆推不伤害权重）
- **新品测词利器**：开 SB 广告投放不同关键词，测试哪个词在无 Review 时转化率最高，再决定是否砸 SP 广告
- 可跳转至旗舰店（Brand Store）或商品集（Product Collection）

### SD 广告（Sponsored Display，展示广告）

- 基于买家标签（Audience Targeting）投放，覆盖站内和站外
- 可干预"Featured items you may like"、"Inspired by your browsing history"等大流量展示位
- 无法通过 ASIN 优化，只能调整出价

## 广告排名得分公式

$$\text{广告排名得分} = \text{广告出价 (Bid)} \times \text{广告质量得分 (Quality Score)}$$

**广告质量得分的构成**（影响因素）：
- 转化率（Conversion Rate）：好评数量、价格、核心卖点约占 80%
- 点击率（CTR）：主图约占 80%；Coupon / 促销标签也有影响
- 广告历史表现（Historical Performance）
- 相关性（Relevance）
- 类目节点（Category Node）

> **新品的广告质量得分是无限大，不是 0。** 利用这个红利，新品期可以开低 Bid 捡漏，或一上来冲高 Bid 快速建立质量得分。

## 三种竞价策略

### 1. 固定竞价（Fixed Bid）

- 不根据售出可能性调整出价
- **新品期首选**：流量最稳定，获得的流量也足够多
- 关键词有曝光但无流量时，先检查是否在前三页；若相关性不够，通过 ECR / 加购 / QA 密度改善

### 2. 动态竞价—仅降低（Dynamic Bids, Down Only）

- 系统在转化可能性低时降低出价，不会提高
- 适用场景：
  - 鸡肋产品（弃之可惜，但推不上去）
  - 不想主推的产品，让其低成本慢跑
  - 新品升级版：用老款开高价只降低捡漏订单

### 3. 动态竞价—提高和降低（Dynamic Bids, Up & Down）

- 系统在转化可能性高时最多将出价提高 100%（TOS）或 50%（商品页面）
- 适用场景：转化率高于类目平均水平的成熟产品
- **新品期不要使用**：会大量亏损，因为大部分时间都在升高出价

**出价计算（配合广告位百分比）**：
- 固定竞价 / 仅降低：`Bid × (1 + 百分比)`
- 提高和降低：`Bid × (1 + 百分比) × 2`

## 广告位置与百分比策略

| 广告位置 | 特征 | 策略建议 |
|----------|------|---------|
| TOS（搜索结果顶部）| 点击率最高，出单效率最高，ACOS 不一定最好 | 提高百分比冲排名 |
| Rest of Search（其余搜索位置）| 消耗弱，转化率最高 | 维持稳定出价 |
| Product Pages（商品页面）| 消耗最弱，转化也高 | 配合 ASIN 定向 |

**实用技巧**：
- 通过设置"TOS 百分比为 0，其他位置百分比为 X"，可控制广告只跑商品页面
- 通过高 TOS 百分比快速冲关键词排名（转化率高时效果显著）
- 卡位打法：`0.1 美金 Bid + 900% TOS 百分比 + Up&Down`

## 自动广告（Auto Campaign）

自动广告有四种匹配方式：

| 匹配类型 | 说明 |
|---------|------|
| 紧密匹配（Close Match）| 搜索词与商品高度相关 |
| 宽泛匹配（Loose Match）| 搜索词泛化匹配 |
| 同类商品（Substitute）| 展示在同类竞品详情页 |
| 关联商品（Complement）| 展示在互补商品详情页 |

**使用原则**：
- 自动广告**不能停**：还有推荐流量和买家标签流量
- 通过精细化调研，新品可以不依赖自动广告跑词（已知主要流量词）
- 捡漏广告（低 Bid + 只降低）：捡取竞争弱的长尾泛词

**10 组自动广告打法（加速收录 & 防止跑偏）**：
- 开 10 个相同出价的自动广告 Campaign
- 连续开一周，中途不做任何否定
- 一次性打开所有流量入口
- 一周后观察哪些表现好、哪些跑偏，保留好的，暂停跑偏的

## 手动广告（Manual Campaign）

**三种匹配方式**：
- **广泛匹配（Broad）**：最大范围发散，适合发现新词
- **词组匹配（Phrase）**：包含关键词短语的搜索词
- **精准匹配（Exact）**：严格匹配特定关键词

**管理原则**：
- 不同匹配方式开不同 Campaign，避免预算互抢
- 升级路径：广泛 → 词组 → 精准，不同阶段独立 Campaign
- 大词 / 核心词单独开 Power Campaign，保证独立预算
- 相似词放同一 Ad Group；大词和长尾词不要混放

**Bid 设置原则**：
- 先看是否在前三页，前三页内曝光不足 = 相关性不够（提 Bid 意义不大）
- 不要频繁调整 Bid（每次调整干扰系统学习，以周为单位优化）
- 手机端 Bid 调整反应比电脑端快，秒杀期间优先看手机端

## 品牌广告进阶打法（SB 高阶）

**全维度闭环广告（新品效果最佳）**：
- SP + ASIN 定向
- SB + ASIN 定向
- SD + ASIN 定向
- 假设有 ASIN1、ASIN2、ASIN3，互相投放 ASIN 定向广告，形成流量闭环

**关联流量截流**：
- SBV（品牌视频广告）+ ASIN 定向：可以从竞争对手 Best Seller（8000+ 评论）的商品页抢订单

**品牌词保护**：
- 品牌词 + 广泛匹配：锁住自己的品牌流量，防止竞争对手截流
- 对手品牌捡漏：手动广泛匹配对手品牌词，低出价捡漏

## 广告预算管理

**推广费用占比目标**：控制在总销售额的 **20% 以内**

**预算分配建议**：
- 不要把预算全砸在站内广告（SP/SB/SD）
- 将一部分预算分配至：站外 Deals、红人合作（Influencer）
- 以 ROI（投资回报率）为导向选择预算分配

**预算问题排查**：
- 广告没曝光：检查 Listing 是否被 A9 收录、关键词相关性、Bid 是否太低
- ACOS 突然上升：检查是否有恶意点击（Impression 突然下降、转化率下降）
- 广告成本增高原因：广告暂停（竞争对手趁机累积数据）、断货、Listing 频繁优化、新增变体分流

## 广告报表分析

| 报表 | 用途 |
|------|------|
| ST Report（搜索词报告）| 核心优化依据；发现高转化词 → 开手动精准；发现无效词 → 否定 |
| 广告位置报表（Placement Report）| 判断哪些关键词在 TOS 表现好，哪些在商品页面表现好 |
| Replacement Report | 判断产品适合关键词流量还是关联流量；新品以 2 周为单位查看 |

**优化频率**：
- 新开广告：给 2 周时间跑数据，不要过早干预
- 现有广告：每周优化一次（建议周二下午）

## 广告与关键词排名的关系

- SP 广告直接助推关键词自然排名，出单越多、排名越快提升
- SB 广告**不影响**关键词权重（链接不带关键词参数）
- 广告是关键词排名的"加速器"，但不能替代 Listing 质量本身

## 排名机制：自然排名与广告排名的底层逻辑（§6）

亚马逊是搜索电商，搜索算法对结果排序求"合理" = 平台收益最大化 + 顾客满意度最大化 = 赛马机制。这套机制是上面所有广告决策的"为什么"。

**ECPM 决定排名**：千次曝光收益 = 曝光 × 点击率 × 转化率 × 价格（= 销售额）。平台给固定曝光考察 CTR/CVR，越高排越前；流量收益最大化是平台终极诉求（亚马逊自己也是 Google/FB 大广告主，流量有成本）。三变量相互影响（客单价高 → CTR/CVR 偏低），最核心是 CTR + CVR。

**预估 CTR/CVR 模型（不是实际值）**：平台用点击率模型 + 转化率模型算分排序，预估的是"下一次展现"的 CTR/CVR，不是最近实际值。A 排在 B 前面，不代表 A 最近 CTR/CVR 比 B 高——平台预估 A 未来表现更好。

**掷骰子类比（核心心智模型）⭐⭐⭐**：实际转化率 = 掷出的结果（短期波动），预估转化率 = 概率均值。两个维度决定预估：

- **时间维度 = 历史权重**：老品过去一年有真实 CTR/CVR 沉淀，时间越近权重越高（7 天 > 1 月 > 半年 > 1 年）。这解释了"老品自然排名为何稳"——即使你 CTR/CVR 更高、短期销量更高，老品的历史权重仍压着你。
- **数据量维度 = 方差**：数据量越大预估越准（方差越小）→ 系统给的权重越高。**反直觉：点击数比点击率更重要**——100 次点击 0.3% 的权重高于 20 次点击 0.6%（系统判断前者风险更小）。数据量到量级时，更低的 CTR/CVR 反而分数更高。

> 班主任选学生类比：四次模考都前十 vs 三次缺考第四次第一名 → 理性选稳定的；但新生差值足够大也能上位。**这两条直接支撑下文"三句认知底座"**：数据量是相关性的基础（方差）、短期数据骗人（实际值短期波动、长期才回归均值）。

**破老品流量护城河两大法宝**：① 力大砸飞（超高广告预算把数据量怡起来）② 差异化款式 / 超低价（带来超高 CTR/CVR）。单纯低价无额外曝光撼不动老品（缺基础曝光 = 质赢量不赢）。

**A9 相关性三层**：词义匹配（买家搜的词 ↔ listing 文案，[[amazon-keyword-library|关键词调研]]的根本原因）+ ASIN-ASIN 匹配（[[amazon-traffic-sources|关联流量]]）+ 匹配基础上的质（该词下 CTR/CVR + 点击/订单数足够）。相关性越强排名越靠前——这就是精准大词卡 top 快速提排名的原理。

### 广告排名 = 自然分配 + bid 变量

- 付费流量 = 自然流量分配基础 + 一个 **bid 变量（权重最大）**。相关性强可用更低 bid 拿位置（降 bid 的逻辑 = 提相关性）；但新品相关性弱，只要 bid 足够高仍能到 top——这是付费 vs 自然的最大区别，也是新品 CPC 比老品高（老品 0.8 拿到的位置新品要 1.4）、新品推广成本高的根因。
- **广告 CTR 参考价值低（反直觉）**：亚马逊广告曝光不等于有效展现。SP 三位置只有 **TOS 是有效展现**（一定被看到）；ROS/PP 可能是无效曝光（买家没翻页/没滚动）。PP 页 CTR 低到 0.01–0.03% ≠ 没人点，是根本没被看到。**所以别看 SP 整体 CTR（三位置混合、随 bid 波动），只用 TOS 位置的 CTR 衡量产品真实点击率**（绝对准确）。

### 自然流量与付费流量的联动

- 自然流量增长 = 更高 CTR/CVR + 更多点击/订单数 → 订单涨则关键词排名自然往前。
- **广告提供两样东西**：① 额外曝光量 ② 更精准的流量（短期稳定 CTR/CVR）。自然流量是亚马逊推荐的、不可控，标签不准/文案不匹配 → 泛流量 → CVR 低；广告把流量引导向精准。
- **流量层级（抖音类比）**：数据好 → 推 100 人 → 赢了推 1000 → 1 万…逐级引爆；自然流量同规律但更慢。
- **广告是流量工具，对转化率无能为力 ⭐⭐⭐**：垃圾产品广告推不爆——广告只赋予更精准更多流量，不能让垃圾产品变好（三分运营七分产品；广告只能让你更快认清产品垃圾）。

四个高频问题（机制澄清）：

- **农村包围城市（打小词带大词）也对也不对**：长尾词流量小 → 数据量小 → 大词推不上去；大词占 90% 流量、长尾占 10%，长尾翻倍也撼不动大词相关性 → 还得打大词。
- **没投广告也能有好排名** = 自然流量层级迭代（CTR/CVR 高于大盘）；但做无优势的通款不打广告进不了下一层级，每天一两单。
- **站外能推关键词**：可以，但量要足够大（推三五百不够）+ 站外人群要和产品契合（标签乱了相关性上不去）。系统发现连续一月日 100 单 → 判定产品好 → 分配相关搜索词曝光 → 进循环。**7D 本质同此效果**。
- **投放词与排名**：投 A 词 A 排名一定升；A/B 相关时投 A 也能带 B 升（慢、效率低，量足够才行）→ 精准打 A 词 + 足够预算拉点击/购买数更高效。

### 降广告花费占比（降 TACoS）的原理

两方向：① 降广告流量占比（提自然关键词排名 + 提关联流量）② 降 CPC。

- **广告流量的重复浪费**：关键词已到头部，SP（打 A 层）还跑在该词 top → 双向曝光（广告+自然两次曝光），但 CVR 不翻倍 = 重复浪费（SP+SD 重合同理）。削减法：减已靠前词的预算 / 降该词竞价改拿 PP 位（与关键词位不重合且便宜）。
- **降 CPC 两种**：① **自动降 bid**（相关性够强，1→0.8 同位置不丢曝光，乐意降）② **强行降 bid**（相关性不够强、清货时，降 bid 丢曝光 → 用更多低价投放稀释综合 CPC）。③ 浮动竞价"仅降低"慎用（亚马逊在低转化时自动压价，但判断权交给平台、易丢大量曝光掉单；仅头部产品适合）。

> 答疑补充：**词组否定不会降权重**——不管广泛还是精准出单，只要搜索词是这个词，对平台没区别（不会因精准打权重就高）；除非想让广泛跑更多长尾、不想出某词才否掉它。优化广告以**点击数据量**为维度（非点击率）：<20 次点击无法判断（除非基础转化率很高），该降竞价用相同预算跑更多点击再判。

## 三句认知底座

- **广告架构只为控制，不为提升表现。** 架构既不影响 CVR 也不影响 ACoS，只影响预算花费效率（管理 / 数据分析 / 把预算花出去）。"好架构能改善广告表现"是运营群最常见的错觉。
- **数据量是相关性的基础。** 数据多 → 平台风险系数小 → 给的相关性高。所以预算要给足、不能断。
- **短期数据是骗人的。** 7 天 ACoS 高的词，拉到 30 天可能完全正常。优化周期最短 1 周、2 周为佳（广告 7 天归因）。

由此推出**广告投放三要素**：精准投放（合格 CVR）+ 足够预算（足够数据量）+ 合适竞价（合适流量优质性）。还有一条反直觉：**转化率长期由产品力 + 市场供求决定**，短期可通过竞价/广告位调，长期回归稳定值——这条划定了广告操作的边界。2021 年后同产品同 CVR 同 CPC 数据下，运营主观能动性差异能造成单量 20 倍量级差距。

## 盈亏平衡 ACoS 与两种策略哲学

**广告盈亏 ACoS = 毛利率**（广告本身不亏的临界点；ACoS < 毛利率，广告就盈利，预算可无上限给）。**目标 ACoS = 容忍亏损度**（毛利 40% + 容忍亏 20% → 目标 ACoS 60%；新品期容忍度高，盈利期收紧）。

广告 6.6 的三种基本目的：理想 = 毛利 ≥ ACoS / 中等 = 毛利 ≥ TACoS / 最坏 = 在可承受亏损内。在限制内无限上预算 = 广告核心操作。

两种策略哲学（关键反直觉）：

- **路径 A：广告必须盈利（传统老板思路）** —— 目标 ACoS 严控 → 容忍流量损失 → 慢慢养链接，牺牲数据量积累速度。手册隐含的就是这条。
- **路径 B：战略性亏损换自然单爆发（现阶段主流）** —— 目标 ACoS 超毛利率 → 广告亏 15% 也接受 → 大数据量快速积累推自然排名 → 自然单覆盖广告亏损。**破除"广告必须每天都盈利"的预设，把优化的时间维度从单天扩展到整个推广周期。**

## 整体盈亏平衡 ACoS（核心升级）

**`整体盈亏 ACoS = 毛利率 ÷ 广告依赖程度`** —— 这是"盈亏平衡 ACoS = 毛利率"的重大升级：后者只保证**广告**不亏，前者保证**整个链接**不亏。

例：毛利 33%、广告依赖 60% 时，ACoS 33% 广告不亏，但 ACoS 55% 整个链接才不亏——容忍度天差地别。**新品期目标 = 整体盈亏即可**（广告本身亏钱不可避，自然单覆盖就 OK）。判 ACoS 高低必须以整体盈亏 ACoS 为参考，不存在跨产品统一阈值（"统一 5%/8%"是错的）。

配套指标拆解：

- **`ACoS = CPC ÷ (客单价 × CVR)`** —— 降 ACoS 的核心是**降 CPC**（提 bid 提位置看似提 CVR，但 CPC 同步抬升）。大促/降价时降 CPC 效果最好（点击率翻 3–4 倍 → 数据量暴增 → 相关性快升 → 同位置可低 CPC 拿）。
- **`CPA = CPC × (1 ÷ CVR)`** —— 广告出一单的成本；CPA = 毛利额时广告盈亏平衡（对应 ACoS = 毛利率）。
- **TACoS 是利润指标，不是广告指标**（反直觉）：TACoS 低 ≠ 广告好，单纯降预算就能压；"新品看 TACoS 不看 ACoS"是错的——新品要看 ACoS，以整体盈亏 ACoS 为容忍度。
- **降 TACoS / 费比两路径**：① 提自然+关联流量；② 降 CPC。低价螺旋本质 = 用更多销售收入降广告费比（广告费比高的产品降价比卷广告更划算）。公司惯例：新品 TACoS ≤ 20%、老品 ≤ 10%。

## 四象限黄金法则（系统化优化决策表）

整门课唯一系统化的优化决策表。**横轴 = 转化率（核心），纵轴 = ACoS（参考整体盈亏 ACoS 与目标 ACoS 双值）**。**第一步永远先判断：预算花完了没有**——预算状态决定调预算还是调竞价。

预算花完时：

| CVR | ACoS | 动作 |
|---|---|---|
| 高 | 高 | **降竞价**（CVR 够用，数据量更重要；降竞价保全天预算 + 拿更多点击） |
| 高 | 低 | **加预算，不动竞价**（广告表现已好，只是预算不够花） |
| 低 | 低 | **提高竞价**（有资本拿高转化流量；CVR 提上去转"高 CVR 低 ACoS"再加预算） |
| 低 | 高 | **降竞价降预算**（淘汰候选：转化差又烧钱；持续如此 → 关闭） |

预算没花完时：优先把预算花出去（加 bid 拉量）；唯独**低 CVR 高 ACoS → 降 bid**（表现差的广告即使预算没花完也不该硬塞钱）。

**调竞价用百分比方式**（5%/3%/2% 一天一调）：从 1.5 调到 1.0 = 33% 大调整，百分比可量化对应 ACoS 降幅。

## 四层级诊断路径（可重复 workflow）

把四象限模型嵌入抽丝剥茧的执行路径：

- **L1 店铺层级**：看 3 个月汇总 ACoS / 点击数 / 花费 / 转化率趋势（汇报给老板那层）。
- **L2 SKU 层级**：推广商品报表下载 + 透视，找需优化的 SKU。
- **L3 广告活动 + 投放层级**：调竞价 / 调预算 / 调架构，数据异常 vs 参考值对比。
- **L4 搜索词层级**：再投放（表现好未投精准的）+ 否词（表现差精准否定）。**用精准否定不用词组否定**（词组否定会丢相关词）。

报告五星权重：★★★★★ 推广商品报告（SKU 维度入口）+ 搜索词报告（信息量最大，买竞品报告主要买这份）；★★★★ **预算报告（被严重低估，多数运营完全不看）**——"平均预算活跃时间"是加预算 vs 降 bid 的前置判断；★★ 已购买商品报告（头部链接抢转化的唯一诊断报告）。

## 低毛利产品无法优化（选品阶段的财务约束）

案例：$22.99 / 毛利 22% / CPC 0.65 / CVR 7.45% / 依赖 60% → CPA 9.29，平均 ACoS 38%，盈亏平衡 ACoS = 22%÷60% ≈ 37.48%——**几乎踩线，稍不留神就亏**。同产品若毛利率 30%，盈亏 ACoS 翻到 51%，优化容忍度倍增。

**元结论（反直觉）：毛利率不够，广告就没法优化。** 多数人把"广告做不好"归咎到广告操作，**80% 是选品阶段的财务结构问题**。"做广告前毛利率要够高"是 [[amazon-product-selection]] 财务模型三角的另一种表述，也与 [[amazon-cashflow-roi]] 一脉相承。

## 架构与操作的若干反直觉

- **SP 广告位认知重塑**：不管投关键词还是投 ASIN、自动还是手动，SP 都是搜索 + 详情页两种广告位（三档 TOS/ROS/PP）。打破"投关键词=搜索位、投 ASIN=详情页"的误区。
- **首页同一产品可 4–5 次曝光**（TOS + 旁边自然位 + Amazon's Choice + Highly Rated + SBV）——这是广告不停的真正原因，很多位置只有付费才有。
- **卡 TOP 两方法**：高基础竞价（云飞扬推荐，可控）vs 低基础 + 高百分比（可能浮动不上去 + 详情页转化拖累）。
- **预算按周分配，不按天**（反直觉）：亚马逊预算释放奔放（给 50 可能花 30 就停）+ 7 天归因 → 按天调易判断失误；按周分配后均分到每天。
- **展示份额第一时换战场**：搜索词展示份额已第一（如 13.47%）→ 不再加预算/bid，预算挪到其他低份额词。
- **BD coupon 软着陆**：BD 结束后用大额 coupon（领取率约 50%）稳 CVR，亏损比直接降价小，防 BD 后排名暴跌。
- 不轻易关词（调竞价/预算 OK，但不轻易关）；新广告没曝光 = 一定是竞价问题（前提 listing/词没问题）。

> 元层级金句："思路对了，操作机械式可自动化"——广告优化的本质是数据驱动 + 流程化，不是技巧驱动。
