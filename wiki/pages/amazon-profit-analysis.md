# 亚马逊利润管理与分析（Amazon Profit Analysis）

利润分析是亚马逊运营的**财务底座**：广告 SOP（[[amazon-ppc-advertising]]）和[[amazon-product-selection|选品]]给的是方法论，财务底座给的是**经营意识**——没有经营意识，方法论就退化成机械执行，失去判断。本页是从财务字段精读 → 退货精算 → 自制工具 → 月度盘点的全栈财务 SOP。

> 财务意识不只是为了卖货，也是为了节省"不该花的钱"。培养财务 + 成本意识是做亚马逊的根本。
>
> 工具（ERP / Excel）不是关键。不懂费用结构，ERP 给的数你也对不上账。

完整 P&L 路径：`收入 − 成本 = 毛利`，`毛利 − 管理费 = 净利`（管理费在公司侧，不在平台 payment 报表里）。

## 收入的四类构成

亚马逊的"收入"远不止订单金额：

| 收入类型 | 说明 |
|---|---|
| 订单收入 | **发出去的才算**。海卖助手/ERP 看的"即时收入"包含还没发货的订单 |
| 退款佣金返还 | 退款时亚马逊返还销售佣金的 **80%**（其余 20% 被扣）——退款的正向收入项 |
| 库存赔偿 | 盘盈（亚马逊把丢失货赔给我们）；盘亏（找到后扣回） |
| 其他杂项 / 货损盘盈 | 零散项 |

**反直觉：真实订单收入 ≈ 即时收入 × 80–90%。** 即时收入有 10–20% 的水分（退款 / 取消 / coupon / promotion）。**后台 payment 的日期范围报告才是真值**，海卖助手的即时数会系统性虚高。

## 成本的八类构成与"真金白银"认知

**核心认知（整门课的现金流原点）：真金白银的前置投入只有采购 + 头程两项。** 其他所有成本（佣金、FBA、广告、退货、仓储、盘亏、管理费）都是从销售收入里扣的，不需要你提前掏钱。这条认知决定了 ROI 的真实分母只有采购 + 头程（详见 [[amazon-cashflow-roi]]）。头程 + 采购占比越低，ROI 越容易做高。

| 成本类型 | 关键点 |
|---|---|
| 采购成本 | **真金白银**，进 ROI 分母 |
| 头程（海运/空派） | **真金白银**，进 ROI 分母；海运货款不进 payment 报表（到仓直接扣余额），自制利润表要单独录入 |
| 平台佣金 | 默认 15%；母婴/个护 + 客单 <10 美金 = 8%。选品要关注佣金分级 |
| FBA 配送费 | 从销售里扣；被多收可开 case 索赔（按 SKU 自查日期范围报告） |
| 广告费 | 从销售里扣 |
| 退货损失 | 见下方退货精算 |
| 仓储费 | payment 报表里没有 SKU 维度，要看 FBA 月度仓储费报表 |
| 盘亏 / 管理费 | 盘亏可季度盘库索赔；管理费在公司侧 |

> **大件 ROI 困境**：大件投成约 13% + 采购约 21% = 34%，意味着净利率要做到 34% 才能 ROI 1:1，极难。大件天然 ROI 低。

**新店铺大礼包 5% 返还机制**：通过平台佣金 + FBA 配送费补贴的形式返还，100 万美金销售额额度对应最多 5 万美金返还。算净利率时可直接 +5%。

## 日期范围报告字段精读

报表位置：payment → 业务/日期范围报告。这是核心财务报表，ERP 的利润算法也基于它。

- **type 五大类**：order / refund / service fee / transfer / adjust。ERP 对账要按 type 拆解。
- **反直觉：`product sales` 字段不含 coupon，但含 promotion 和秒杀。** 很多人统计销售额时没扣 coupon → 数据虚高；coupon 单独在折扣字段里。
- 礼品包装费 3.99 美金/单（Q4 高发）。产品频繁被选礼品包装时，自己做彩盒（国内 2 块钱）可省 4 美金成本并提转化。
- 销售税：美国后扣、欧洲含税，均由平台代扣代缴，与卖家无关。
- **FBA 配送费被多收（如 3.7 涨到 4.25）可开 case 索赔。**

## 退款 ≠ 退货（利润分析用退款率）

**行业普遍混淆这两个概念。**

退款有四种情形：退款+退货 / 退款+取消订单 / 退款+换货 / 退款+不退货（平台赔偿）。其中**只有一种是真退货**，所以**退款率必然高于退货率**。退货才进退货报告（要完整退到仓库 + 验收才算）。

**利润分析用退款率**——它更全面，因为退款无论是否退货，损失都已发生。

## 三种退货情形的精确利润计算

以客单价 99.99 / 佣金 15 / 配送费 15.12 / 实际回款 69.87 为例（回款额包含产品成本 + 投成 + 毛利）：

| 退货情形 | 利润影响 | 损失结构 |
|---|---|---|
| **情况 1：不可售退货** | **毛利率 −60%（利润杀手）** | 产品成本 + 投成 + 平台费 18.12 + 仓储均摊 + 广告均摊 + 销毁/移仓费，共 9 道损失 |
| **情况 2：可售退货** | 损失约 22%（毛利率 ≥22% 则不赚不赔） | 配送费 15.12 + 3 道佣金（约 20%）+ 广告均摊 + 仓储均摊 |
| **情况 3：平台赔偿（退款不退货）** | **反盈利 +18.47%** | 亚马逊按"定价 − 佣金 − 配送费"（回款额 69.59）赔付，比正常销售还赚 |

**退货成本由 6 项构成**：产品成本 + 投成 + 平台费 + 仓储均摊 + 广告均摊 + 销毁/移仓费。算退货时少算一项就会低估亏损。

> **ERP 先进先出原则**：不可售退货当月不计损失，销毁时才算；可售退货当月计损失。所以 ERP 利润报表里的退货损失常滞后 2–3 个月才体现。

## Adjust 调整费用与季度盘库

`type = adjust` 四类：买家退货 / 仓库损坏 / 一般性调整 / 丢失。读数规则：**正数 = 亚马逊赔我们，负数 = 亚马逊从我们扣**。赔偿额约等于"定价 − 佣金 − 配送费"（没算广告/仓储，所以是有利润的赔偿）。

**季度盘库找丢失货**：`月初发 100 − 接收 95 − 销毁 X − 退货 Y − 月末库存 Z = 丢失`。亚马逊不主动赔，需开 case 提供货代签收单 + 采购发票 + 合同。订单量大时索赔工具划算，否则自己每季度盘一次。

## FBA 仓储费与其他费用的反直觉扣费机制

- **海运费（AGL/龙舟）不进 payment 报表**：货到仓直接扣余额，自制利润表要单独录入。
- **广告费按周扣 + 满 500 才收**：不是花多少扣多少，是一周一次性收。ERP 分摊时要按周对账。
- **SB/SD 广告归因不到 SKU → 按销售额比例分摊**：SP 广告报告里有 SKU 可精确分摊；SB+SD 是品牌/展示型，只能按销售额比例摊。
- Transfer（回款）月度对账：payment 表 transfer 列总和 vs 收款工具实际到账，差异开 case。

## 自制 Excel 利润表 vs ERP

ERP 年费 7000–15000，个人卖家和初创前期负担不起。自制 Excel 是完整替代方案：

- **三个数据源全免费**：日期范围报告 + 库存管理报表 + FBA 月度仓储费报表，后台都能下载。
- **SKU 成本一次性录入**：父子 ASIN / FBA 费用 / 产品成本 / 投成成本 → 用 VLOOKUP 进所有报表（与 ERP 的产品资料维护逻辑相同）。
- **总表 + SKU 利润双层**：店铺整体 + SKU 维度同时呈现。
- **库存货值估算 = 产品成本 + 投成**，用于资金占用评估——现金流闭环的关键工具（详见 [[amazon-cashflow-roi]] 与 [[amazon-inventory-replenishment]] 的月度货值/回款比）。

> 自制表仅适配美国站。欧洲税务结构不同（VAT 含税），需自调公式。

## SKU 利润诊断现场

诊断用四列：**现象 / 原因 / 应对 / 复盘**。每月对每个 SKU 走一次，不是只看销量，要看每项成本占比。

**关键阈值：成本占比 > 20% 说明售价偏低**（成本占比 = 产品成本 / 销售额），意味着定价没有为广告和利润留空间。新品广告占比 18–27% 属正常范围（对应新品期容忍度高），成熟期应严控在 10% 以内。

两个 SKU 的对照诊断：

| | 成本占比 | 广告占比 | 毛利 | 诊断 |
|---|---|---|---|---|
| SKU 1 | 20% | 18% | 1.41% | 售价偏低但存活 → 提价试错，看转化能否撑住 |
| SKU 2 | 24% | 27% | **−14.59%** | **卖一个亏一个，直接淘汰候选** |

**诊断主线：低价 + 低转化 = 价格手段失效，直接淘汰。** 这与[[amazon-product-selection|选品]]测款本质、低毛利产品困境、"让产品适应你的标准"贯通——这种产品在选品阶段就该被 pass 掉。成熟期做月度环比（这月比上月利润减 5% → 哪项成本变化导致？单点突破）。

## 月度业务盘点：5 + 3 维度

**运营 5 维度**（运营 KPI 全集）：销量 / 利润 / 库存 / 广告 / 新品复盘。月初强制全店盘点，不是只汇报销量。

**老板视角再加 3 维**：选品 / 店铺现金流 / 库存周转。现金流 + 周转是经营者独有的指标，运营常忽略。

> **秒杀节奏硬约束**：同月只能 1 次 7DD，两次 7DD 间隔 21 天（活动规划时要算好，详见 [[amazon-pricing-strategy]]）。

## 元层级金句

- **真金白银投入只有采购 + 头程** —— 现金流认知的原点
- **退款率 ≠ 退货率** —— 利润分析的口径前提
- **培养经营意识 = 财务底座的真实价值** —— 利润分析每月做一次，纠正"只看销量"的惯性：挣了多少钱比卖了多少单重要，销量不能直接换算成利润
