# 亚马逊关键词词库（Amazon Keyword Library）

云飞扬把关键词词库从"运营阶段的技术活"重新定义成**公司财富 + 类目护城河 + 垂直深耕引擎**——这是手册（[[listing-optimization]] 只讲"关键词收集体系"）完全空白的视角。本页讲怎么把关键词做成持续增值的资产，并接上小红圈"相关性 2.0"的工具实操层。与 [[amazon-data-driven-operations|数据化运营]]（关键词四象限源头）、[[amazon-ppc-advertising|广告]]（投放）、[[amazon-new-product-launch|新品推广]]（评级 ABCD）贯通。

> 元层级金句：**"广告投放做不好后面都没意义，词库是投放的前提。"** 与"选品 → 测款 → 推广"同构。

## 词库 = 财富，搜索 = 词的映射

- **词库是公司财富 + 类目护城河**：动态更新机制 = 垂直类目越做越香的根源。工具降低了门槛，但谁调研更深谁胜出。
- **搜索本质 = 买家搜索词 ↔ listing 关键词的映射**（不管 SP 还是自然搜索）；关键词 = 搜索词的聚合，调研搜索词 → 反推关键词，**不是预设后填词**。
- **选词三原则：大 / 精准 / 便宜**——大词（流量）+ 精准词（高转化率）+ 便宜词（低 CPC）三轴评估。
- **选品阶段就做词库，不等产品到货**（反直觉）：在词库里能发现场景/功能改进点。

## 词库建立三步法

**找对标竞品 → 反查关键词 → 梳理关键词。**

- **对标竞品 ≥ 50 个（实操 66 个）**（反直觉）：传统 10 个 ASIN 不够，占位率算法需要更大样本。选头部 + 腰部（只选头部会丢腰部的主要流量词与长尾词）+ 新品榜 5–10 个（抓头部未蹭中的趋势词）。
- 变体差异大 → 以目标产品拓词；变体差异小（服装类）→ 以 listing 拓词更准。
- **全部流量词都要（自然 + 广告）**：广告词是竞卖真金白银投过的，相关性强。

## Sif 占位率筛选法（技术核心）

**占位率定义**：某关键词下自然位前 4/8/16/48 名中，目标对标产品的占比 = 量化"相关性"的公式。

- **占位率背后的逻辑反推（元层级）**：能到自然位首页 = 在该词下出过单且转化较高 = 强相关。所以对标产品占自然位前 N = 强相关性证据。
- 选位：大类目选 48 位 / 蓝海选前 4（对标不到 5 个时只能看前 4，避免百分百失去判断力）。
- 一键 listing 拓词（1981 词）→ 高级筛选清洗（→ 222 词的量级）。**综合相关性第一次要大而全（默认值 10%）**，词不够再降。
- **筛 ABA 100 万以内，而不是 Sif 搜索量**（反直觉）：ABA 是亚马逊官方有直观印象，Sif 自己算的搜索量不准。关键词单词数 ≥ 2（1 词太泛）。
- **手动标记不相关词 + 词组否定**（反直觉）：white / outdoor / 鞋柜（closet）这类。**不相关词下产品出现 ≠ 该词适合投放**（Shoe Closet 下你有自然排名但转化率差，仍要否定）。

## 词根分析 + 长尾归类

- **词根分析法：几百词 → 2–3 个主词**（shoe rack / shoe organizer / shoe storage）。
- 长尾词 5 维归类：场景（closet/garage/entryway）/ 材质（metal）/ 层数（3 tier）/ 颜色（black）/ 尺寸（large）。
- **"用顾客搜的词写文案，不用自己的表达"**（反直觉）：多数人中文设计后翻译，云飞扬反向——从词库扒表达（文案细节见 [[listing-optimization]] 的"云飞扬文案补充"）。多语种更要从词库找词（jewellery vs jewelry 美英差别）。

## 广告投放四象限 + 词库工程化

**两轴：流量 × CPA**（成本维度，不是 ACoS）。低/高是相对你产品的，不跨类目比。

| 象限           | 决策                |
| ------------ | ----------------- |
| **A 低价高流量**  | **首选**（投放优先级最高）   |
| B 低价低流量（长尾词） | 优先（转化高，量小但性价比高）   |
| C 高价高流量      | 预算够再覆盖（广告词多数在此象限） |
| **D 高价低流量**  | **直接否定/放弃**       |

**关键词打标签 A/B/C/D 入词库** = 词库工程化点，助理看表即可投放（评级 SOP 化见 [[amazon-new-product-launch]] 的投放评级）。

**VLOOKUP 动态词库（7.7）**：三数据源（广告 ST 报告 / ABA 品牌分析 / 词库本身）用 VLOOKUP 拼到同一词库；数据源更新 → 词库自动同步。这套**动态更新机制 = 垂直深耕的核心**。

## 测词以词根为突破点

- **不撒网测，以主词词根为突破点**（反直觉）：多数人等分预算测多词，云飞扬集中打主词及其长尾。
- 预算紧 = 多词 + 拉长时间；预算足 = 大词 + 短周期（100 美金 3 天 ≈ 20 美金 2 周）。
- 测词本质 = 测 CPA + 转化率（与 [[amazon-product-selection]] 测款本质贯通）；**词高相关性 ≠ 高转化**（供大于求 → 转化低 + CPC 高 = 性价比差）。测出后反哺词库。

# 相关性 2.0（小红圈 3-30）：从手动否词到占位率算法

小红圈知识星球第 3-30 期直播，主题是**关键词调研工具的代际跨越**——从"看 listing/review + 手动否词 + 半天"→"84 对标产品 + Sif 占位率算法 + 10 分钟"。这是上面 Sif 占位率法的工具实操版 + 非标品打法延伸。

## 工具原理：listing 拓词 + 5 维占位率 + 加权总相关性

- **listing 方式拓词**：84 对标 × 40 变体 = 3428 变体 → 2648 词（多变体特征极强类目典型，如苹果表带）。整个 listing 所有 ASIN 的流量词合并去重。
- **5 维占位率**：前 4 / 8 / 16 / 32 / 48——容量大用前 4（严格）/ 容量小用前 48（避免失去判断力）。
- **加权"总相关性"** = Sif 把 5 维占位率加权成单一总分（工具核心输出）。
- listing 拓词 vs 关键词拓词：变体差异小（颜色/材质）用 listing 拓词；变体强行合并了款式/功能差异大的，用关键词拓词找最爆变体单拓。

## 实操数据流：2648 → 408 → 198（10 分钟）

高级筛选 5 条件：相关性 20–100% / ABA 1–50 万 / 单词数 ≥2 / 占位率（48 位）50–100% / listing 方式。

- **反直觉：相关性 30% 还可容忍**——全新类目要容错率高，20% 是底线，宁可宽筛后人工标记。
- **词频统计找否词**：皮革/魔术贴/Ultra/野径回环/SOLO loop/米兰尼斯（官方款式专名）——**词组否定 > 单词否定**（提取共同词根一次解决一类）。
- 主词库（ABA 20 万内，精细投放）+ 长尾词组（20–50 万，扔一组全开）。在线词库（看动态趋势）+ Excel 词库（便于分析）并存。
- 苹果配色/款式专名必须与官方一致才精准（新人先去官网看官方命名）。

## 非标品的反直觉：词根可组合 ≠ 关键词多

嘉宾琴琴诊断非标品困境（自动/广泛投很久没位置 + 出单词分散 + CPC 1.2+ + 转化率仅 5%）：

- **非标品本质 = 词根可组合，不是关键词多**：5 词根（尺寸/型号/人群/颜色/材质/特性）全打乱组合 → 排列爆炸。**投放词不分散，但出单词极分散**。可投放词其实有限。
- **类目竞争激烈是钱的问题，不是关键词的问题**：对手每天 300/500/1000 美金——诊断要分清"方法问题"vs"资源问题"。
- 标品 vs 非标品中间灰色地带不要纠结，按具体问题分析。

## 跨类目 ASIN 定投案例（整节最深）

讲师自创审美向装饰品（义乌底座 + 自加摆件，提供情绪价值，无明确品类词）：测款 20 美金/天自动、7–10 天卖完 200 个、转化率 10%，但**出单词全场景分散**（宿舍/女卧/办公室/浴室）。

**关键决策：不打关键词，改打跨类目 ASIN 定投**——

- **500 个跨类目 ASIN 定投（完全跨类目，找需求/情绪价值一致的产品，不限同类目）+ 2 组自动（前置否核心词避免抢自己精准位）**。
- 200–250 美金/天投 2–3 个月（广告依赖极高，60–70 单广告/20 单自然）→ **2–3 个月后关键词自然排名跑到首页**（没打关键词广告却把自然排名打上去）→ 半年稳定 120 单/天，后期广告降到 25 美金仍稳定。
- **本质 = 现金奶牛打法：别人投不起，你上去后难下来**（前期烧出来的位置 = 后期护城河，与 [[amazon-cashflow-roi]] "老链接现金奶牛"机制一致）。

## CPC 控制与关联流量的反直觉

- **CPC 控制：Bid 0.7–0.8 但只给 0.35–0.4**（类目竞价高也不抬）；**用大量投放消化预算 ≠ 抬 bid**（CPC 低但花不完 → 不停加新 ASIN 定投，用投放数量替代竞价高度）。
- **关联流量取决于购物习惯**：逛街式购买（服装/装饰品，跳来跳去停留久）→ 关联流量曝光多；直接买（标品/零部件）→ 关联流量位少。优秀非标品不打广告也能出 30+ 单。
- 找跨类目 ASIN 的方法：从"情绪价值一致"而非"品类一致"切入（如 miniso 常并排陈列的两个不同产品）。
- 讲师诚实承认搞不清的事：非标品广告关了自然单反而涨——广告转化率拖了整体转化率后腿，亚马逊推荐算法精度 > 广告投放技巧。
