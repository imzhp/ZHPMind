# 批判性思维中的写作和表达

## 核心原则

批判性思维不仅是**如何评估他人的想法**，也是**如何表达自己的想法**。

一个强势的批判性思维者不仅能识别他人论证中的问题，还能避免在自己的表达中犯同样的错误。

---

## 前置条件：责任原则

> **"想说服别人，你有责任说清楚。"**

```
如果读者/听众不理解你的观点，
通常不是他们的问题——是你的表达有问题。

你的工作：
✓ 说清楚你的论题和结论
✓ 提供充分的理由
✓ 使用精确的语言
✓ 预见并解答反对意见
✓ 明确说明假设
✓ 承认信息的局限性
```

---

## 第一步：明确你的论点

### 1. 明确论题

```
不要这样做：
"我想讨论教育改革"
→ 太宽泛了

这样做：
"我主张在高中必须实施为期一学年的社会情感学习项目"
→ 清晰、具体、可论证
```

### 2. 清楚地陈述结论

```
不好的结论：
"教育很重要，社会应该关注它"
→ 模糊、含糊、显而易见

好的结论：
"学校应该将60%的预算用于课堂教学，
而不是体育和设施维护，
因为[具体理由]"
→ 具体、可论证、明确你的立场
```

### 3. 区分论题和结论

```
论题（主题）：气候变化
    ↓
结论（你的主张）：
- "气候变化主要由人类活动导致"（可辩论）
- "气候变化需要政府干预"（可辩论）
- "气候变化是真实的"（大多数科学家同意）

重点：同一论题可以导出不同的结论
你需要明确说出是哪一个
```

---

## 第二步：提供充分的理由

### 理由vs装饰

```
装饰（显得聪明但无关）：
"X是对的，因为现在时代不同了"
→ 没有真正的理由

充分的理由：
"X应该改变，因为：
1. 数据显示[具体证据]
2. 许多成功的案例表明[具体例子]
3. 专家同意，原因是[具体解释]"
→ 每个理由都直接支持结论
```

### 理由的质量

```
等级制：
🔴 最弱：个人意见或情感
   "我感到X应该这样"

🟡 更好：一个例子或案例
   "Y公司成功地实施了X"

🟢 好：多个例子或案例
   "许多公司实施了X，结果如下..."

🟢🟢 更好：统计或研究数据
   "一项对1000家公司的研究显示X的结果..."

🟢🟢🟢 最好：来自多个来源的证据
    + 理解为什么会这样
    + 承认有什么证据与你不同
```

### 理由数量

```
最少要求：至少2-3个独立的理由
          如果你只有1个理由，那可能还不够强

更好的做法：3-5个中等理由比1个完美理由更有说服力

太多？：如果你列了10+个理由，
       可能需要整理和组织它们
       或者承认一些不如其他理由强
```

## 第三步：使用精确的语言

### 问题：模糊的关键词

```
❌ 避免含糊不清的词汇：
"好的"、"坏的"、"真的"、"重要"、"有效"

✅ 具体化：
不要说："这个政策很好"
要说：  "这个政策降低了失业率15%"
       "这个政策改善了学生成绩"
       "这个政策成本低且容易实施"
       （具体说明"好"意味着什么）
```

### 定义关键术语

```
如果你使用可能有歧义的术语，先定义它：

"我用'成功'来指代：
✓ 用户采用率超过50%
✓ 客户满意度评分≥4/5
✓ 成本不超过预算的110%"

这样读者知道你的意思，而不是他们的理解
```

### 避免绝对语言（除非你能证明）

```
❌ 绝对语言：
"所有X都..."
"永远..."
"从不..."
"每个人都..."

✅ 更准确的语言：
"大多数X..."
"通常..."
"在某些情况下..."
"许多人..."

好处：更难被攻击，更符合事实
成本：声音不够强硬（但更诚实）
```

### 主动vs被动语态

```
被动：
"有人指出，研究表明..."
→ 谁？什么研究？

主动：
"Smith（2020）的研究显示..."
→ 清晰、具体、可核实

建议：在批判性写作中使用主动语态
     这使你为陈述负责
```

## 第四步：识别和陈述你的假设

### 隐含假设的危险

```
如果你不明确你的假设，
读者会填补空白——
通常以对你不利的方式填补。
```

### 识别你的假设

```
问自己：
1. "为什么这个论证有效？"
2. "什么必须是真实的才能使这成立？"
3. "读者可能反对什么？"
4. "我在哪里做出了跳跃假设？"

然后明确陈述这些假设：

"这个论证假设：
□ X是真实的（事实性假设）
□ Y比Z更重要（价值观假设）
□ 当前条件保持不变（关于未来的假设）"
```

### 例子

```
论证："学校应该减少标准化测试"

隐含的假设：
1. 标准化测试有负面影响（事实假设）
2. 学生福祉比可测量的成果更重要（价值观假设）
3. 有更好的替代方案（事实假设）
4. 学校有实施替代方案的资源（实际假设）

更好的表述：
"鉴于以下假设...
我主张应该减少标准化测试：
- 假设：研究显示高压测试对学生心理健康有害
- 假设：我优先考虑学生幸福感而不仅仅是分数
- 假设：替代评估方法（如组合）同样有效

如果任何这些假设是错误的，我的论证会减弱。"
```

## 第五步：避免论证谬误

### 在自己的写作中检查常见谬误

```
在完成写作后，问自己：

□ 循环论证：我有没有用结论本身作为证据？
   例："X是对的，因为X是对的"

□ 人身攻击：我有没有攻击提议人而不是论证？
   例："你错了，因为你很愚蠢"

□ 虚假二分：我有没有忽视第三选项？
   例："要么全采纳，要么全拒绝"

□ 非此即彼：我有没有扭曲对方的观点？
   例："如果你不同意我，你就是反对进步"

□ 乐队花车：我有没有因为"大家都这样"就说它是对的？
   例："所有聪慧的人都同意这一点"

□ 相关性混淆：我有没有声称因果关系而只有相关性？
   例："两者同时增长，所以一个导致另一个"

□ 诉诸权威：我有没有盲目接受权威而不评估论证？
   例："专家说是这样，所以它一定是对的"
```

## 第六步：考虑反对意见

### 预期和回应批评

```
强大的论证预见反对意见：

"反对这个观点的人可能会说：
[陈述最强的反对意见]

我的回应是：
[说明你的论证如何处理这个反对意见]
[或承认这是一个有效的点，但这样修改你的主张...]"

好处：
✓ 显示你已经考虑过
✓ 显示你不害怕反对意见
✓ 让你的论证更强
✓ 表明强势的批判性思维
```

### 什么时候承认反对意见

```
"我的论证在这些情况下最强：[陈述]
但它可能在这些情况下较弱：[陈述]"

这不会削弱你的论证——
它会加强它，因为你看起来诚实和深思熟虑。
```

## 第七步：指出省略的信息

### 你应该告知读者的内容

```
"这个分析基于[时间段]的数据"
→ 如果你的数据已经过时了怎么办？

"这个研究在[位置/背景]进行"
→ 结果可能不适用于所有地方

"这个论证在[这些条件]下成立"
→ 如果条件改变会发生什么？

"我无法获得[这个数据]"
→ 如果有怎么办？
```

### 建立信任

```
通过指出局限性，你：
✓ 显示了诚实和透明
✓ 建立了信任
✓ 向读者表明你理解问题的复杂性
✓ 预先解决了他们可能提出的问题
```

## 实际检查清单：发布前

在提交、发布或呈现你的论证之前：

### 论题和结论
- [ ] 我的论题是什么？（主题是什么？）
- [ ] 我的结论是什么？（我声称什么？）
- [ ] 它们是清晰和具体的吗？
- [ ] 是否可论证（不是显而易见的事实或意见问题）？

### 理由和证据
- [ ] 我有至少2-3个独立的理由吗？
- [ ] 每个理由都直接支持我的结论吗？
- [ ] 我的证据是相关的、足够的、可靠的吗？
- [ ] 我是否引用了来源？

### 语言清晰度
- [ ] 我是否定义了可能有歧义的关键术语？
- [ ] 是否有含糊的词汇我应该具体化？
- [ ] 是否有太多的绝对语言我应该软化？
- [ ] 我的语言是否精确和适当的？

### 假设
- [ ] 我认识到我的假设吗？
- [ ] 我是否明确陈述了主要假设？
- [ ] 如果某个关键假设错误，我的论证是否崩溃？

### 逻辑谬误
- [ ] 我有没有犯任何明显的逻辑谬误？
- [ ] 我的推理是否合理和有效？
- [ ] 我是否遵循了从理由到结论的逻辑步骤？

### 反对意见
- [ ] 我是否考虑了主要的反对意见？
- [ ] 我的论证如何处理它们？
- [ ] 我是否应该纳入反对意见和我的回应？

### 省略的信息
- [ ] 读者应该知道什么限制或背景？
- [ ] 我的数据/研究有多近期？
- [ ] 这些发现在其他情况/人群中适用吗？
- [ ] 有什么可能的反对证据我应该提及？

### 整体清晰度
- [ ] 如果一个聪慧的陌生人读我的东西，他会理解吗？
- [ ] 论点是否易于遵循？
- [ ] 结论是否清晰？
- [ ] 我是否提供了足够的上下文？

## 强势批判性思维中的沟通

### 语调和方法

```
❌ 弱势批判性思维的沟通：
- 居高临下
- 试图"赢得"论点
- 显示你有多聪明
- 攻击反对者
→ 对话结束，人们变得防守

✅ 强势批判性思维的沟通：
- 尊重
- 真诚好奇
- 倾听更多说话
- 寻求相互理解
→ 对话深化，双方都学到东西
```

### 好的批判性表述示例

```
"这是一个有趣的观点。我有点困惑[具体]。
你能帮我理解一下吗？"
→ 显示好奇，不是攻击性

"我注意到这两个论据似乎相互矛盾。
我想我一定是误解了什么。
你能澄清一下吗？"
→ 提出问题，给对方救场机会

"我从不同的角度看这个问题。
也许两个观点都有有效的观点？"
→ 开放性，不是对抗性

"我的初始反应是[X]，但你让我思考[Y]。
我现在不确定了。你能帮我思考这个吗？"
→ 谦虚，表现出愿意改变想法
```
